# C135 selected-group translation gizmo

OBRush's viewport translation gizmo now captures the scene's selected IDs and uses their mean world center. During a drag, all captured members receive the same shader-only translation in the filled mesh, wire overlay, contour and transparent ordering; their saved meshes and GPU vertex/index buffers do not change until release. Release verifies the captured active ID, selected IDs and document revision, then calls the C134 shared-core atomic selected-group transform for one Undo entry. Escape, focus loss and exact-return gestures retain the earlier cancellation/no-op behavior. The numeric selected-group transform remains available.

The normal-browser check imports an independently authored two-part `.obrush` sphere scene, Ctrl-clicks the second member in the scene panel, switches to Transform mode and drags the actual world-X handle through 15 pointer moves. Its measured preview and committed translation are `(+0.4318220615386963, 0, 0)` world units. **Both** solid draws expose that identical shader preview while their captured vertex/index buffers and document revision remain unchanged. After release, the maximum per-component position errors against the measured translation are `6.1538696360941e-8` and `1.6153869619728312e-7` for the two objects. The group pivot is the average of the two object centers; one release increments the document revision once. The committed GPU buffers match the public saved project; Undo and Redo recover its exact project hashes.

The same frozen WASM (`61317455b3a470bbe1e1f4aa4ee111acd4189e312c648850c64f48d4eb62fb21`) passed all **nine** `scripts/check-transforms.mjs` browser workflows, including the preceding single-part numeric, preview, cancellation, late-release and legacy-file gates. The [receipt](evidence/sculptgl-selected-group-gizmo-c135.json) links the raw result, fixture, harness, build and failed-check status. No new browser attempt failed; earlier C134 numeric-field scrolling failures remain separately retained.

The final source passed `cargo fmt --all --check`, workspace/all-target tests (**2,462 passed, zero failed, one ignored**), strict native and WASM Clippy, `scripts/build-web.sh`, `scripts/package-macos.sh` and `codesign --verify --deep --strict`. The signed native executable SHA-256 is `bbeedd84b63c0bdb83509d2f07c2092ae1dd8824b8399472304ca904b2109995`. Native GUI interaction was not run.

This is a selected-group translation foundation, **not** SculptGL transform parity. The pinned SculptGL group gizmo includes three planar translation handles, rotation arcs, view-axis rotation, uniform and nonuniform scale, and mask-weighted vertex transforms; these are absent or unpaired here. This run does not compare the source's group gizmo on identical input, a third unselected object's preview, hidden/transparent multi-part cases, native pointer use or sustained drag latency.
