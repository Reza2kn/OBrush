# Sculpting foundations in OBrush 0.1.6

This iteration adds manual voxel remeshing, constrained triangle decimation, persistent Loop subdivision levels, pressure controls and PNG brush alphas to the shared Rust core and browser/native hosts. These are independently written foundations. They do not establish ZBrush 2026.2.1 or SculptGL parity. The current version does not yet establish the entire suggested SculptGL-core milestone. The scene still contains one mesh; multiple objects, quad retopology, automatic decimation during sculpting, MatCap/PBR, UVs, layers and additional interchange formats remain work.

## Using the new tools

The Object inspector contains **Add subdivision level**, **Lower** and **Higher**. Add on the highest level; edit a coarse level to adjust the broad shape, then return to a finer level. Stored fine detail follows coarse edits as additive world-space offsets. These vectors do not rotate or scale with a reshaped patch. Fine geometry, mask and color edits do not project down to coarse levels; a fine-level mask does not automatically protect a coarse-level edit. Large deformations can distort detail. Persistent levels keep fixed topology, so brush-local refinement is disabled while a stack exists. Small marks require an appropriate selected level.

**Rebuild / reduce surface** exposes **Voxel remesh** with resolution 16–128 and **Decimate** with a keep-face percentage. Both replace the active topology and stored levels; Undo restores the complete prior hierarchy. **Refine without smoothing** also replaces stored levels, with undo available. Remeshing can soften small features and requires closed, consistently connected source solids. It treats closed components as solid unions; nested cavity shells and open sheets are unsupported. Decimation protects nonzero masks, boundaries and detected sharp features. It may stop above the requested count; the footer reports its termination reason. Remeshing interpolates masks and colors from the nearest original surface; narrow protected/painted features can blur. Work/allocation limits and rejected results preserve the current sculpt. Jobs run on a native thread or browser worker, and can be cancelled while orbiting.

Browser pen pressure scales strength by default; radius scaling is optional. Mouse input uses full nominal pressure. Native force events are consumed when supplied by the host, but physical tablet input and calibration are unverified. Captured pressure is sampled at application input updates; this is not a claim that every raw device event is replayed. Radius-dependent dab spacing is selected at stroke start and does not continuously resample when force changes. The radius control and cursor outline show nominal size; the pressure-scaled footprint can be smaller.

**Import PNG alpha** takes a PNG no larger than 16 MiB / 1024 pixels per side. The shared core converts RGB to 8-bit grayscale and multiplies by opacity. White permits sculpting; black and transparent pixels protect the surface. Bilinear sampling and rotation use the local projected brush plane; asymmetric stamps mirror with X symmetry. The image weights the existing radial falloff. Non-square images stretch to the footprint; this is not UV projection or vector displacement. Geometry density limits stamp detail, and alphas/brush settings remain session state.

## Project and history contract

Version 2 `.obrush` JSON stores the active mesh and optional subdivision metadata, including ordered inactive meshes, active index and a versioned Loop/world-offset scheme. The active slot is null in metadata to avoid serializing the same mesh twice. Version 1 files remain readable. Hierarchy topology, nonzero triangle areas, channel lengths, finite values, indices, counts and version are validated before replacing a document; malformed metadata is rejected, not ignored. OBJ exports only the active mesh.

The unique subdivision levels share the one-million vertex / two-million triangle limits, with at most eight levels. Encoded projects remain limited to 128 MiB. History stores whole document snapshots, capped at 64 operations / 128 MiB of reserved snapshot storage; active geometry, the current stroke snapshot, rendering buffers and temporary work are additional memory. Level navigation is not an undo entry. Adding levels, sculpting and topology replacement are undoable operations. No-op decimation preserves both hierarchy and redo.

## Recorded geometry checks

The [decimation receipt](evidence/topology-decimation.json) records three independently sourced fixtures, exact settings, source hashes, boundary/winding checks, deterministic sampled surface distances and native CPU timings. At 50% retained faces, the supplied sculpt falls from 123,156 to 61,578 triangles. Its signed volume changes by about −0.00577%; the largest of 1,024 sampled distances in each direction is about 0.000355 world units. Sampling is not an exact Hausdorff bound or a global intersection check. The user supplied the sculpt; other fixtures were independently authored.

The [remeshing receipt](evidence/topology-remesh.json) preserves the sphere, box, overlapping/touching-solid and damaged-sculpt runs at multiple resolutions, including failures. Healthy fixtures remain closed/manifold and do not create adjacent folds above 90°. **The damaged user sculpt is not reliably repaired.** At resolution 64, its edge-fold length above 90° increases from about 1.0192 to 2.258 world units, although it is closed/manifold. A bounded field-smoothing experiment also failed the predeclared gates and was removed. Low resolution can lose thin features or change component count. These failures are retained; the remesher is not labelled an automatic tear repair.

The [pressure/alpha receipt](evidence/brush-inputs.json) records nine final browser cases, including real DOM pen events generated through Chrome CDP. Zero pressure and black alpha are exact no-ops; mouse matches pen-full and white alpha matches the normal brush exactly. Quarter pressure gives median displacement ratio 0.249999334 with maximum component error 7.5e-8 under the preregistered 3e-7 bound. Radius modulation reduces the affected old-vertex set from 630 to 172; rotation changes the geometry. Asymmetric stamps mirror 20,353 old vertex pairs exactly. Packed GPU buffers match saved meshes before Save, and undo/redo plus oversized-PNG rejection pass. These are correctness checks using generated events, not physical tablet measurements.

The [sustained-browser regression](evidence/sculpting-foundations-browser.json) replays 20-second Draw and Crease schedules on the original 61,580-vertex / 123,156-triangle user sculpt. Release to the last mesh-buffer upload measures 19.3 ms for Draw and 18.0 ms for Crease; both queues end empty. No measured phase has a main-thread task above 50 ms. Pre-Save GPU buffers match exported meshes, two later saves are stable, and undo/redo restores every mesh field exactly. Atomic dabs still take time: callback p95 is about 21.2 / 19.4 ms, and rAF p95 reaches 33.3 ms. These are headless scheduling/submission measurements, not physical input-to-photon latency or a claim of replaying every captured motion sample.

The [subdivision receipt](evidence/multiresolution.json) checks the default 40,962 → 163,842 vertex level creation through real canvas controls. Fine Draw/Mask/Paint and coarse Draw keep topology fixed; the matched coarse branch is bitexact and retained fine residuals differ by at most 1.0e-7 components (preregistered limit 2e-6). Mask/RGB edits survive exactly. Save/load, malformed hierarchy rejection, whole-state undo/redo and primitive replacement pass with packed GPU equality. Observed main-thread tasks include Add 165 ms and one fine Draw task 56 ms. A separate single targeted run observes Lower 92 ms, Higher after a coarse edit 238 ms and export 175–190 ms. These are scoped headless observations, not reference or physical latency claims; startup/background activity was not fully controlled.

The [topology browser receipt](evidence/topology-browser.json) exercises eight workflows: default/supplied remesh and decimation, cancellation with brush locking, rejected open-sheet remesh, protected no-op with redo, and primitive replacement while a worker is active. Whole-project history and pre-Save GPU equality pass. All eight worker-origin WASM deliveries and seventeen total WASM responses match the tested candidate hash. End-to-end jobs take about 574–640 ms in this scoped run, including preparation, cold worker startup and acceptance; two phases contain a 53 ms main-thread task and busy rAF gaps reach 33.4 ms. These are headless observations and do not establish native GUI or physical input latency.

A final inspector-width correction is validated separately in [layout/runtime evidence](evidence/topology-browser-layout.json): all eight workflows pass, bars/values fit, and all four geometry outputs are byte-identical to the preceding candidate. Those timings overlap the required test rerun and are not performance claims. The [build record](evidence/sculpting-foundations-build.json) identifies both exact runtime artifacts and the one-statement UI-only source delta; earlier pressure/subdivision/long-stroke measurements remain attached to their original runtime hashes. The final source passes 142 tests (126 core, 16 app), formatting and strict native/WASM Clippy; browser and ad-hoc-signed macOS builds pass. Native CPU timings exclude host input/output serialization, rendering and history; successful native builds do not establish native tablet or GUI interaction.
