# C100: paired seam-aware UV subdivision

The frozen [SculptGL inventory](SCULPTGL_PARITY.md) calls for independent triangle, quad and mixed UV-seam comparisons. C100 exercises one static smooth subdivision through the actual pinned SculptGL and OBrush browser controls on the **same independently authored OBJ bytes**. Each face has a separate UV island. The tetra has four triangles, the cube six quads, and the pyramid one quad plus four triangles. Both browser runs used isolated Chrome 155.0.8059.80 profiles and completed without touching a user tab.

| Seamed quad cube | 6 / 24 | 24 / 54 | 1.7954e-8 | 0 |
| Seamed mixed pyramid | 5 / 16 | 20 / 33 | 2.7633e-9 | 2.6703e-8 |

The comparator pairs faces by their physical coordinates and then pairs their corners by position. This is necessary because the importers order vertices, faces and UV IDs differently. All 16, 24 and 20 physical child faces map, as do all 48, 96 and 64 corresponding child corners. The initial OBJ face/corner maps also agree. Exact native Rust versus browser WASM `f32` words and face/UV indices agree for all six parent and child meshes. The browser saved each stage and matched actual visible GPU buffers to the saved scene; Add Level undo/redo, Lower and Higher checks passed. These are structural and numerical UV results, not a checker-texture pixel or saved-project reload comparison.

**Level navigation remains different.** SculptGL's `lowerAnalysis` copies its fine level's smoothed even vertices into the coarse mesh when lowering. On these fixtures, the first Lower changes 12, 24 and 13 coarse position components by up to `0.75`, `0.4444444` and `0.7272727` scene units, while the UV coordinates and face-UV indices remain exact. Higher then changes a few fine position components by at most `1.4901e-8` on the tetra, `2.9976e-17` on the cube and `8.5787e-9` on the pyramid. OBrush deliberately retains the original coarse mesh and an exact fine return in its current multiresolution implementation. Therefore this comparison **does not close** the complete SculptGL static subdivision or multiresolution navigation gate, even though the first fine-level UV mapping matches.

The paired numbers are observational, with no preregistered acceptance tolerance. Other seam-sharing patterns, two or more levels, UV texture pixels, native GUI, large meshes, physical pen input and sustained performance remain unverified. The separate WebGPU prototype does not participate; the delivered browser path remains Rust/WASM CPU geometry and WebGL2 drawing. [The evidence record](evidence/sculptgl-uv-subdivision-c100-0.1.20.json) identifies the pinned reference bundle, exact fixture/build hashes, captured browser output, native probe and comparator. The reference's changed coarse positions are a newly measured gap; they are not reported as an OBrush test failure because current OBrush navigation has a different documented contract.
