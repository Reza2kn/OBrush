# Source Worker GPU normal oracle: static diagnosis and falsifiable gate

Review date: 2026-10-19. Root inspected at `ce0f0de`; no browser, Cargo, or product-code run was made for this review. The untouched frozen `SP-WORKER-01` verifier remains failed.

## What the existing failure proves

`scripts/audit-source-gpu-words.py::canonical_words` hashes the public Save's `mesh.normals`. `scripts/source-gpu-readback-observer.js` extracts the second three f32 words of the active 40-byte VBO row. These are different concepts on an imported Source object. `renderer.rs::source_normal_policy` selects `StaticOriginalFaces` when scene metadata exists. `GpuMesh::upload` chooses `packed_geometry_rows` with a `SourceNormalField` before a retained state exists, and `packed_selected_row` with `SourceGeometryNormalState::vertex_normals()` after a selected-refresh producer exists; neither necessarily emits `mesh.normals`. `paint_scene_with_geometry_normals` attaches the document's retained state to the active `RenderObject`. The held Worker bridge separately captures baseline display normals, checks preview display-normal rows, and publishes a decoded retained state through `SourceWorkerColdCapture::commit_candidate_checked` and `Document::publish_cold_source_worker_result`. Its final candidate delta checks *public* position and normal words, a distinct invariant.

The existing 100k ordinary and Worker receipts both have untouched Before/Undo public normal SHA-256 `69e1025160b4...` and actual GPU normal `02a0c38496e4...`, with exact VBO positions and one active buffer. The independent original-face static oracle `scripts/audit-source-static-display-normals.py` produces the actual GPU hash at Before/Undo. Thus the all-stage public-mesh-normal failure is demonstrably an incompatible oracle in the untouched state; it does not by itself show bad Worker rendering. The Worker receipt `100k-worker-588e764b...` has equal After/Stable/Redo GPU hashes `496de286...`; the ordinary control `100k-ordinary-563fc0c1...` has After/Stable `100311cd...` and Redo `b5af30b5...` despite equal public Save bytes. This latter divergence is not proof of a product bug or proof of correctness. `source_history.rs::prepare_source_history` starts from the **current** retained state and `SourceGeometryNormalState::refreshed_for_history` refreshes only selected rows; its public project cannot encode that path-dependent state. A separate pinned SculptGL Drag audit (`docs/SCULPTGL_SOURCE_DRAG_C288_RESULT.md`) also observed a reference-side After/Redo display-normal difference, though it is a different gesture and cannot validate this Worker result.

## Diagnostic to distinguish oracle error from product defect

1. **Freeze provenance and exact states.** Keep the current `SP-WORKER-01` protocol/hash/verifier and its failing public-normal result untouched. Choose an independently authored small curved Source scene whose `mesh.normals` deliberately differ from original-face normals; include a flat plain-Studio control where legacy `mesh.normals` *should* reach the VBO. Record exact fixture, served build, style/metadata, public files, one active VBO, error-free GL, and f32 position/normal streams for Before, live preview, After, Stable, Undo, Redo and cancellation. A Before failure in the plain-Studio control would indicate an auditor/renderer problem outside Source semantics.
2. **Independent fresh-state oracle.** Reuse the separately written Python face-order/f64-mean/f32-boundary oracle in `scripts/audit-source-static-display-normals.py`. It must match Source Before and an Undo that is known to reseed; it must differ from authored public `mesh.normals` in a useful number of rows. Do not infer expected edited normals by recomputing all faces from an edited public Save: retained selected-refresh deliberately leaves unselected rows untouched.
3. **Independent edited-state oracle.** Capture exact trusted delivered input, worker-accepted sequence, selected vertex IDs per accepted dab, original face ordering and triangle/quad correspondence, and the transient retained state generation at each publication/history edge as *read-only* diagnostics. Implement an independent replay outside product Rust: seed the fresh face and vertex arrays, for each ordered selection update affected face normals and only selected vertex means in the defined descending incident order with f32 assignment boundaries, retain unselected rows, then apply the captured history selection to the current field on Undo/Redo. Self-check the replay on tiny analytically solvable triangle/quad fixtures and perturb one selected ID, one normal word, face order, and one history step to prove its assertions fail. Compare **every** captured GPU normal f32 word against replay at each state; use `scripts/audit-source-display-normal-rows.py` for the existing bounded 100k raw-stream comparison, but do not treat a comparison between two product streams as an independent oracle. For 1m, stream bounded chunks to binary artifacts and hash/compare all words without embedding a 16 MB base64 stream in a 1 MB receipt.
4. **Discriminating failure rules.** If the independent replay matches the retained producer but not the VBO, investigate `renderer.rs::packed_selected_row`, `GpuMesh::upload`, sparse preview gap fill/restore and cache identity; that is a rendering defect. If the producer and VBO match each other but both differ from replay, investigate core selected-face/ring/history semantics; that is a geometry-state defect or a flawed replay to resolve against pinned SculptGL normal UI. If only the public `mesh.normals` differ and replay matches producer/VBO, the old frozen check is an oracle error for this Source mode. Compare the same delivered dab sequence and retained normal stream for ordinary versus Worker; different accepted sequences cannot prove branch equivalence. Require a post-Undo next stroke to test that the Worker-adopted retained field is usable, and a cancellation with exact baseline VBO restoration.
5. **Admission policy.** Never flip `gpu_position_normal_all_states` to true or suppress its historical failure. Because `SP-WORKER-01` explicitly equates VBO and serialized mesh normals, its unchanged gate cannot admit the intentional Source display policy. A prospective versioned protocol must be preregistered with the independent display-normal oracle and preserve the old verifier result alongside the new one. Until the edited-state replay and normal browser 100k/1m performance/history/queue gates pass, keep Worker query-gated and make no responsiveness, SculptGL, or ZBrush parity claim.
