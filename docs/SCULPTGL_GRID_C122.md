# C122: source-style scene grid in the normal studio

This is a scoped implementation of `SGL-RENDER-GRID`, **not a SculptGL parity result**. The pinned source revision is `8e45dafc0f7906e5238dfffc1a2df742bd25f29d`. Its `createGridArray` defaults to 22 positions along each of two XZ axes (44 line segments / 88 endpoints); `Scene.initGrid` translates the floor to Y = -0.45, scales it by 2.5, and assigns flat color 0.04. Reference source hashes: `Primitives.js` `2b9b10126d5e689a518c74a8c2b0e3024891de7a589530341965ef3f57bd0836`; `Scene.js` `092d17a08278700d6d85d3f8b9880e9152ce8c71be607fbe1584d0c5b5602f52`.

OBRush now renders those fixed endpoints with a small separate GL/WebGL2 program in the ordinary viewport. The grid is drawn into the depth-tested opaque scene before meshes, matching the source's pass order. Its real environment-panel checkbox uses the existing localized `renderingGrid` caption. Imported SGL display headers set the visible grid flag; subsequent SGL export reads the current flag. The contour bit remains preserved source provenance without a render pass. This is view state and does not edit geometry, project or undo history.
