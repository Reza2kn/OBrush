# C175: session history length

SculptGL's pinned source exposes a 3–50 `Max Stack` control with a default stack length of 15. OBrush now offers the same range in the normal inspector. The setting lives in the shared Rust `Document`; new edits trim the oldest Undo entries at the selected count, and lowering the count trims existing Undo and Redo stacks. The independent byte budget still applies to large scenes. The setting is session-only and does not change the versioned project JSON.

Core checks cover default 15, selected 50, lowering to 3, Undo/Redo order, invalid values, whole-file replacement, and save independence. The initial normal browser check sets 3 through the visible slider, adds five spheres through the visible Scene control, observes only three available Undo steps, then restores the exact saved project through Redo. It also sets 50 and 10 through the visible slider without changing the exported project bytes. Initial browser receipt: `.artifacts/history-limit/2a5a3206-8b74-4601-9fbb-f2c2eb02f2ea/result.json`; initial WASM SHA-256: `796520a7c0880177a61c730ba96cb7a8cb0cf119dfc7498ef0499bdee5bb6ff5`.

The pinned hosted SculptGL bundle (`79b24bf6e1818cbb468c53cfe49783de419fd3e58f72b220aeb9308932e47600`) was then driven through its visible State and Scene menus. Its 3-step cap retains three of five sphere additions, fourth Undo is a no-op, Redo recovers the exact exported SGL, and 50/10 leave the export unchanged. In a second branch with six available Undo and three Redo actions, lowering 10 → 3 retains three Undo actions and discards all Redo. OBrush's previous equal-side eviction differed; shared Rust now follows this observed nearest-past-first rule. The same visible OBrush branch produces `(undo,redo)=(6,3)→(3,0)` while preserving exact project bytes. Pinned and OBrush receipts: `.artifacts/history-limit/source-3ba8bb46-48b0-407f-a28e-b7392f133976/result.json` and `.artifacts/history-limit/2183ed6d-12da-4e02-8f90-9caaefd24d14/result.json`; final WASM SHA-256: `f0d1f48e8685cd410aca97e0aa75d7f240260d844dfd7e625c45553e01cadf07`.

`cargo fmt --all -- --check`, workspace tests, strict native/WASM Clippy, the official web build, and the official macOS package are the local checks. Earlier browser attempts failed because the test hovered over an incorrect sidebar region or clicked the slider's numeric field; their receipts remain in `.artifacts/history-limit/`. The final UI separates the translated label and narrows the slider to keep its full track within the browser window.

This is a bounded paired workflow check, not SculptGL history-family parity. Mixed scene/mesh edits, exact memory-pressure behavior, persistence preferences, and long-session native/browser behavior remain unverified.
