# C113: checked document-to-GPU-input snapshot

The portable core can now capture the **visible active subtool** of an ordinary `Document` as `ResidentDocumentInput`. It validates the mesh and any imported object metadata, bounds the derived arrays through the existing 128 MiB resident-input cap, and owns the copied positions, normals, colors and triangle indices. It also carries the active subtool ID and the exact local-to-world f32 matrix. An empty document or hidden active subtool is rejected before allocation. The document remains the sole authority for edits, undo and save; the snapshot cannot write positions back.

The existing `ResidentPointInput::capture(&Mesh)` still requires explicit `UnprotectedF32V1` masks. The document boundary also accepts a fresh sphere with protected masks: it converts each raw mask to transient f32 **influence** for the point shader, records the original convention and counts words that would differ on an inverse f32 conversion. No document masks are changed. This is a numerical limitation for fractional masks, not a claim of exact protected-mask parity. A production GPU stroke path must either retain native mask semantics in shader storage or establish an acceptable paired tolerance before it can replace the CPU path.

The checked transformed-import test uses the independently authored `tetra-13-v3-le.sgl` fixture (SHA-256 `6b92a73c37f250f96032c49638c9d452cf79a69669abd8c56ac5c996225ef16a`). It checks all 16 pose words bitwise and confirms `Document::to_json()` is unchanged. A fresh `Mesh::sphere(2)` test checks identity pose, unchanged save state, owned positions after document mutation, and hidden/empty rejection. A protected-mask test uses raw f32 `0.0010000000474974513` (`0x3a83126f`): its transient influence is `0.9990000128746033` (`0x3f7fbe77`), and converting that back would yield `0.0009999871253967285` (`0x3a831200`). Exactly one word is reported changed; the document retains `0x3a83126f`. There is no ZBrush or SculptGL reference comparison for this plumbing step.

The first targeted test run had one failed assertion because this SGL fixture already uses `UnprotectedF32V1`, contrary to the test's assumption. The assertion was corrected to check the imported convention explicitly; the separate fresh-sphere test covers the protected convention. This failure is retained here rather than discarded.

After correction, `cargo fmt --all -- --check`, `cargo test --workspace`, strict native all-target Clippy, strict core/GPU WASM Clippy and app WASM check passed. The [C113 evidence](evidence/sculptgl-webgpu-document-c113.json) records source, fixture and test-binary hashes and the exact fractional-mask words.

This is **not** a studio renderer switch or complete GPU brush. It captures one active subtool, and no normal OBrush UI path consumes the result yet. Multi-subtool drawing/picking, use of the carried pose in a live canvas, contact selection, real brush deformation, normals, history transaction, CPU fallback, device recovery, and the unchanged million-vertex 60/120-second browser gates remain open.
