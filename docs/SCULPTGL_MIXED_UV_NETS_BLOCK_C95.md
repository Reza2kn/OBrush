# C95: mixed-UV selected Smooth Surface Nets and Block

This run extends the C94 explicit UV-discard workflow to the other two exposed selected voxel-remesh modes. The independently authored overlapping boxes, one with UVs and one without, were imported in right-then-left selected order into OBrush and the pinned SculptGL reference. The source OBJ hashes, reference bundle hash, and shared-core behavior are recorded in [C94](SCULPTGL_MIXED_UV_FUSION_C94.md). These runs used resolution 16; Smooth Surface Nets used Block off, and Block used Block on. SculptGL's selected-mesh Remesh control and OBrush's visible selected-remesh controls were used.

Each paired output has 1,058 vertices and 1,056 quads. After one-to-one vertex mapping, all 1,056 oriented quads match in each mode. Smooth Surface Nets has maximum/RMS browser-save world-position differences of `1.461773076125217e-7` / `7.701678175151223e-8`; Block has `1.891323773108724e-7` / `8.882498795924513e-8`. The maximum RGB and roughness/metallic differences are `2.7055358842176247e-8` and `2.384185793236071e-8` in each mode. Unmasked weights match exactly. The [C95 evidence index](evidence/sculptgl-mixed-uv-nets-block-c95-0.1.20.json) records the exact reference, browser and comparison output hashes.

Both isolated browser workflows confirmed that the default operation rejects without changing the canonical project, the visible UV-discard consent enables fusion, the fused output has no UVs, undo/redo is exact, and the rendered GPU buffers match the saved document. The browser served WASM SHA-256 `b6b05475e6e4df4323ef62896e9f22243b712d25c510d8f173e31693924e9722`. The pinned reference bundle SHA-256 was `79b24bf6e1818cbb468c53cfe49783de419fd3e58f72b220aeb9308932e47600`.

One concurrent Block browser launch failed before any case with `TypeError: fetch failed`. Its failed receipt is retained. The same workflow passed when run alone from a new isolated profile. This suggests startup contention, but the failure was not independently diagnosed; it is not evidence about Block geometry.

The fixture uses per-vertex UV coordinates without a seam and constant unmasked weight. Arbitrary seams, nonuniform masks, affine selected parts, larger/longer scenes, native GUI execution and physical input remain unverified. Matching this pair does not establish full SculptGL remeshing parity or ZBrush parity. Production WebGPU compute/draw remains separate from the WASM CPU/WebGL2 browser application.
