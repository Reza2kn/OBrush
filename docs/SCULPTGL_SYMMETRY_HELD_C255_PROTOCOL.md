# C255 preregistration: browser-held Source symmetry offset

This is a proposed next gate, frozen before its first browser run. It is a narrow paired consumer check of the existing C255 per-object symmetry-offset foundation, **not** closure of either SculptGL ledger row. Source is pinned at `8e45dafc0f7906e5238dfffc1a2df742bd25f29d`; its hosted bundle SHA-256 is `79b24bf6e1818cbb468c53cfe49783de419fd3e58f72b220aeb9308932e47600`. Both browsers import the independent 540-byte `independent-affine-two-mesh.sgl`, SHA-256 `99e107226fd5bdfeb687a4d92a61eebcec1abb2e910184e35aa58808ace105fd`, and keep the authored active triangle at local Z=0 with translation Z=+0.5. OBrush explicitly converts the imported protected mask before ordinary Source brushing. That conversion is recorded as a workflow difference.

Set the active object's normalized SymOffset to exactly `+0.5` using its visible numeric control in OBrush, and the reference scene's SymOffset control callback. Require X symmetry enabled, ordinary Draw, alpha None, and the same nominal radius/intensity only if both public controls can be verified; otherwise record a setup failure rather than silently using defaults. The fixed local path is `(3.84,-1.70,0)`, `(3.835,-1.71,0)`, `(3.83,-1.72,0)`. With the pinned loose AABB `[1,-2,-1,4,2,1]`, the reference plane X is `3.8462913036346436`; the reflected path has X `3.8525826`, `3.8575826`, `3.8625826`. Original and reflected points lie inside face 0 before deformation. Transform to world with the imported object matrix, project with each browser's own camera, and dispatch a held mouse press, two moves and release through Chrome's input protocol. Freeze pointer pressure as mouse (not pen). Record actual projected CSS coordinates and reject points outside the sculpt canvas.

Capture full screenshots immediately before and after the gesture, with the cursor parked away from the specimen at each capture. Decode the PNGs and count changed RGB pixels with a per-channel threshold of 4 in a square centered on each projected stroke, radius 90 CSS pixels. Each host must have at least 20 changed pixels in that ROI; report the counts, ratio, bounding boxes, screenshot SHA-256s, and full geometry/history/stroke diagnostics. Both hosts must deliver the held stroke, mutate the active face, and leave peer-object identity intact. OBrush's completed ordinary Source report must identify a mirrored contact on the active triangle and the offset plane. Reference's symmetry picker must identify face 0 during the held stroke. Preserve any failed run's receipt and screenshots. Pixel-count agreement, brush shape, per-vertex numeric parity, native GUI, save/undo, and later large-mesh performance remain separate gates; a passing pixel-change check alone cannot close the ledger rows.

The candidate runner is `scripts/check-sculptgl-symmetry-held-c255.mjs`. It writes an immutable per-run directory in ignored `.artifacts/sculptgl-symmetry-held-c255/`, including the exact build and script hashes, result JSON, and PNGs. Build with `scripts/build-web.sh` before the run and invoke `node scripts/check-sculptgl-symmetry-held-c255.mjs web/dist .tools/sculptgl-reference/host-mirror`. Run in an owned Chrome profile and preserve failed outputs.
