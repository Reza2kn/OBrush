# C94: selected remesh with mixed UV coverage

The selected-remesh path previously rejected a textured SubTool paired with an untextured SubTool before reaching its explicit `allow_uv_loss` policy. It now keeps original sources for UV-sensitive voxel triangle order and constructs a temporary UV-free concatenation only after the user allows UV discard. The report counts the discarded coordinates and faces from the original source. Rejection leaves the document and undo/redo untouched.

The independent pair is `independent-fusion-left-uv.obj` (8 vertices, 12 triangles, 8 UV coordinates and 12 UV-indexed faces) and `independent-fusion-right.obj` (8 vertices, 12 triangles, no UV). Both contain explicit `#MRGB` and `#MAT` channels. Their SHA-256 hashes are `ee68f293a081e38c8575b62494f5a826d3b3bfc3bd3b099f7878be0e09778102` and `9600c7b964ac0b35ebafda32d889f96bda59799ecc0e65092b5fa598ba924dbf`. The reference is the pinned SculptGL bundle SHA-256 `79b24bf6e1818cbb468c53cfe49783de419fd3e58f72b220aeb9308932e47600` with mirror HTML SHA-256 `a87cc1246a6bc39cebf81b78dcf6d6c5c6201ef72710dab7f177d1fe4acd11f0`. These are source-created fixtures; no commercial binary or licensed source is included.

The matched browser/reference runs selected both boxes in right-then-left order and ran Marching Cubes at resolution 16, with Relax topology off and on. The OBrush browser used WASM SHA-256 `b6b05475e6e4df4323ef62896e9f22243b712d25c510d8f173e31693924e9722`. Both outputs have 1,056 vertices and 2,108 triangles. All 2,108 oriented triangles match after one-to-one unrelaxed vertex mapping. Maximum reference-to-browser position difference is `1.451e-7` world units with Relax off and `3.246e-7` with Relax on; Relax-on RMS is `1.138e-7`. Across the mapped vertices, maximum RGB difference is `2.706e-8`, maximum material difference is `2.384e-8`, and unmasked weights match exactly. The [comparison record](../.artifacts/mixed-uv-c94-comparison.json) is local output; the persistent [evidence index](evidence/sculptgl-mixed-uv-fusion-c94-0.1.20.json) records its hash and source paths.

An isolated browser run verified the visible default rejection before consent, the visible discard-UV control, exact undo/redo, GPU/save agreement and zero GL/JS errors for both Relax settings. The core test verifies that Marching Cubes, Smooth Surface Nets and Block all reject without consent, report 8 discarded UV coordinates and 12 faces after consent, and restore the textured source exactly on undo. Formatting, workspace tests, strict native/WASM Clippy, WASM target check, official web build and signed native package are recorded in the evidence index.

This is one overlapping-box pair. It does not prove mixed-UV behavior on seams, nonuniform masks, arbitrary meshes or selected transforms. SculptGL parity for the remesh family and browser responsiveness remain open. The production browser still edits geometry in Rust/WASM on the CPU and renders with WebGL2; the separate WebGPU work has not been integrated into this workflow.
