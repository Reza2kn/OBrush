# C190 uniform scale ring and pinned scale gesture policy

The normal OBrush Transform viewport now presents an orange annular handle for uniform scale in addition to the X/Y/Z cubes. Axis and ring drags share a camera-frozen, absolute screen-distance gesture. The pinned SculptGL source at commit `8e45dafc0f7906e5238dfffc1a2df742bd25f29d`, `src/editing/Gizmo.js` (SHA-256 `e56a6e70f0eb2d53dd30240aa8a93c16258a3605b0a885aab743b6cb07df3c6c`) calculates scale from the current pointer radius divided by the initial radius, with a 0.01 minimum. Axis cubes first project the pointer onto the screen-space axis; the uniform ring uses the whole radial distance. OBrush now follows those rules for both handle types, with an explicit 1000 upper limit inherited from its shared-core transform validation.

The held preview composes world-pivot scale into the same rendered matrices used by geometry, contour and wire views while leaving the saved document and mesh buffers intact. Release sends one selected-group world-axis scale transaction to `obrush-core`; the ring supplies equal XYZ factors. The existing mask option applies unprotected vertex weights at commit. The release, command barrier, cancellation and Undo/Redo paths are shared with the translation and axis-scale gizmos.
