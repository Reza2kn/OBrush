# C109: repeated static Reverse

OBrush now prepends a second recovered smooth level while preserving every retained finer level. Reverse remains available only at the lowest source-static smooth level. The shared Rust core maps each new child vertex to its old physical origin through even vertices, true edges and oriented parent faces; it copies sculpt positions, colors, masks and materials through those maps and rebuilds source-frame ring maps for the new hierarchy. It rejects UV-bearing retained levels until their coordinate IDs and corners can be mapped without loss. Candidate construction, aggregate allocation checks and scene preflight happen before the document/history transaction.

The [C109 evidence](evidence/sculptgl-reverse-c109.json) pairs a nonplanar, independently authored 5×5 quad grid in an isolated pinned SculptGL browser and OBrush browser. The exact same 25-vertex/16-face OBJ (SHA-256 `5dd968cb2ac58f5e04802e3360e0226962085752a6c57b2805f25272965607e5`) was imported into both. The reference kernel SHA-256 is `79b24bf6e1818cbb468c53cfe49783de419fd3e58f72b220aeb9308932e47600`. The rebuilt OBrush WASM SHA-256 and both run receipts are in the evidence file. Both normal UI paths reach 25/16 → 9/4 → 4/1 vertices/faces. The imported, first-reversed and second-reversed physical positions and oriented face multisets match exactly. After raising twice, oriented faces still match; eight of 25 reference vertices differ slightly from OBrush's preserved source positions, with maximum mapped 3D distance `7.450580596923828e-9` world units. This is an observed fixture difference, not an accepted general tolerance.

The normal OBrush browser run passes two Reverse clicks, middle/fine navigation, exact second-command undo/redo, lower return, saved-project reload and 19 complete GPU/save checks across the scoped reverse group. The core test verifies a nonidentity root permutation, preserves an edited fine-level position/color/mask/material on its physical vertex, checks project reload and second-command history, and confirms a later coarse edit propagates through both recovered levels.
