# C119: GPU-owned sparse changed-row readback

The isolated Rust `obrush-gpu` viewport now compares resident positions against its GPU checkpoint, counts bitwise-changed vertices in one compute pass, and compacts their `u32` IDs plus RGBA32F positions in another. The output is sorted by ID in Rust and submitted to C118's checked sparse document transaction. The count and exact payload allocations are bounded; invalid count changes, out-of-range or duplicate IDs, missing checkpoints, device errors and resource-cap overflow reject. The shared `obrush-core` document still owns validation, history and serialization.

On the independently generated 162-vertex sphere, native Metal and browser WebGPU returned identical **140 sparse bytes** (SHA-256 `676cf71a17d0dd637053e8b69ee0c4265f46a30481ed7f731c95c79f4401117b`) for seven vertices, IDs `[25,84,85,88,89,147,149]`. Both accepted the identical complete `.obrush` project (SHA-256 `78ee164193035562df3690cd6c399dd9a1f8fa8c1aefc132eb986a86d4cc47c5`), matching the earlier full-buffer result. Browser invalid and stale sparse inputs rejected; Undo/Redo restored exact complete project strings. Native zero-change checkpoint and cancel checks returned empty sparse outputs. Browser offscreen and visible canvas images changed.

The browser GPU trace has **no full-position readback**. The edit sequence maps a 4-byte failure word, 4-byte changed count, 140-byte compact result and 4-byte post-collection count. Two separate 1 MiB image diagnostic maps captured before/after pixels. Initial mesh upload, GPU position/checkpoint copies and GPU compute still occur. This is a measured transfer-size reduction for one local diagnostic point pass, not an end-to-end latency or sustained brush-speed result. The normal OBrush studio still uses CPU/WASM geometry and WebGL2; the prototype has no general brush, multi-subtool live composition, source-tool parity, GPU device-loss recovery or continuous history integration.

The first native probe failed GPU bind-group validation because the checkpoint buffer lacked storage usage. The corrected run and original failure are retained in `.artifacts/gpu-compact-c119/native/` and terminal history. The final source passed formatting, **2,453 workspace/all-target tests** (one ignored), strict native workspace Clippy and strict core/GPU WASM Clippy. Final Metal and owned-browser runs passed; the browser process exited zero, its server closed, and no JavaScript/GPU error or external request was recorded. [Evidence](evidence/sculptgl-webgpu-compact-c119.json) records hashes, exact parameters and the remaining gaps; raw traces and screenshots are in ignored `.artifacts/gpu-compact-c119/`.
