The [remaining gate inventory](SCULPTGL_REMAINING_GATES_0_1_16.md) and [feature contract](FEATURE_PARITY.md) still apply.

## Data and transaction behavior

`Mesh.masks` remains the sole canonical f32 channel. Legacy `protected_f32_v1` is the omitted default, retaining existing valid-project behavior. Explicit `unprotected_f32_v1` stores source-style unmasked weights without a lossy complement round trip and requires project version 7 in active, retained or inactive mesh data. Display conversion never writes back into that channel. Snapshot Undo restores exact original words; repeated scalar Invert can still round, as recorded separately in the independent source-mask ledger.

Fill affects selected RGB/roughness/metallic channels on the visible active part, weighted by the canonical unmasked fraction. It ignores dab radius/strength/alpha/pressure and makes one complete undo step only for a useful edit. Disabled channels, fully protected points and no-op redo remain intact. The paint picker uses all original face corners with inverse-distance interpolation, preserves authoritative render-row identity for repeated triangle triples, and changes tool targets without sculpt/history edits. Exact-corner and undefined-geometry handling are explicit OBrush policies, not a blanket numerical equivalence claim.

Deleting lower/higher levels retains the active shape, materials, UVs, layers and subdivision scheme. A retained singleton remains fixed topology and requires at least v6; canonical source masks independently require v7. Morph Target removal/rebasing is reported and undoable. Pending first material Paint is accepted before a useful deletion reconciles its hierarchy; no-op deletion does not split a pending stroke. Structural Reverse remains a separate core prototype; arbitrary imported correspondence cannot yet be installed into Document history.

## Host and rendering limits

Per-tool settings and the shared alpha library are held in memory for the app session. Native/WASM PNG decoding preserves original hidden RGB, with explicit mean-RGB and legacy weighted-opacity import choices. Continuous sculpting and source-kernel compatibility remain separately staged. Restart persistence, JPEG and matching bundled presets remain open.

UV seams use a separate render-only geometry/UV mapping; welded sculpt topology is preserved. Ordinary Studio/PBR/Normal paths retain their 40-byte vertex and optional 8-byte material streams. PNG viewport textures use bounded decoding and request ownership, so newer selection/reset can reject an older response. Curvature and opacity are global controls. Per-object style persistence, MatCap/environment/filmic rendering, backgrounds, texture baking and exact intersecting transparency remain open. Generated checker/alpha presets are not represented as reference asset equivalents.
