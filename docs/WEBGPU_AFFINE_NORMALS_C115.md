# C115: affine-normal lighting in the isolated WebGPU document probe

The separate `obrush-gpu` document canvas now transforms each retained local vertex normal with the saved object's inverse-transpose linear pose before lighting. Its position camera remains separate. The 160-byte draw view uniform carries both transforms, and the diagnostic local-camera path supplies an identity normal transform. A reflected or sheared object therefore no longer receives lighting as though its normals had stayed in local orientation. The normal OBrush studio still uses WASM CPU geometry and WebGL2.

The independently authored source fixture is `crates/obrush-gpu/tests/fixtures/reflected-shear-v3.sgl` (SHA-256 `dbf724eacab383f647ec8f36655424d53cb14cf60e74d258ea10a169f8ee5c69`). The checked 2,467-byte versioned project `reflected-shear-nonplanar-v7.obrush` (SHA-256 `cc3ebbca73d6c2de2ac2d8a53a5421a2beba4fc4ddf3af7229a9f4d96b49b895`) is an OBrush save of that source with local vertex 2 set to `z=0.5` and vertex 4 set to `z=-0.25`. Its pose has a reflection, shear, unequal axis scales and translation `[262144,-131072,4096]`. The nonplanar faces give a visible test of normal orientation; the earlier planar fixture could not discriminate the old and new lighting well. No proprietary assets were used.

The camera is the shared `SourceCameraFrame` orthographic 512×512 setup from C114: identity view rotation, 45° FOV parameter, zero plane offset, zoom `13.65`, and a world camera composed with the saved object pose in f64. The same seven visible pixel-center world rays at x/y `96,160,224,288,352,416` were checked through core CPU picking, native Metal and browser WebGPU. Browser and native local GPU hit records match exactly; all seven GPU face IDs equal the CPU picker. The largest browser GPU versus CPU world-hit position component difference is `8.578626875532791e-8` world units. The complete native and browser 512×512 offscreen RGBA images match exactly. The actual browser canvas screenshot's RGB channels also match the offscreen image at all pixels; its PNG omits alpha.

An A/B native Metal run holding the project, camera and shader constant while supplying identity normal transform changes **23,120 pixels** and **67,441 RGBA channels** relative to the transformed result; the largest channel difference is 31. At pixel `(256,256)` transformed RGBA is `(88,5,144,255)`, versus `(79,5,128,255)` with the old local normals. A hand-calculated unit test checks a different reflected/sheared affine basis: local X normal maps to `(0.5,0.5,0)`, Y to `(0,-1,0)` and Z to `(0,0,2)` before normalization. Invalid/singular poses are rejected before publishing a new camera uniform.

The owned browser trace shows two indexed draws of nine indices, fourteen 8-byte pick maps, no full-position readback and one later 1 MiB explicit image diagnostic map. Its GPU error, exception and console-error arrays are empty; the owned Chrome process exited zero and the server closed. A separate unchanged 999,002-vertex / 1,998,000-triangle local-camera native regression retained the C112 perspective PNG SHA-256 `5b2d9d6cc8df7c56a9c4d28af53b944e626dea8d918eff59a83f4b565ba85b57` and orthographic PNG SHA-256 `556fba60439cd51f5e09723cd9601d42e6eb3039974f42c982cf7bbe87cb1f74`; named camera picks were unchanged. These checks establish this probe's GPU consistency and the lighting transform's visible effect, **not** SculptGL or ZBrush appearance parity.

Formatting, all 2,448 workspace tests, strict native workspace Clippy, strict core/GPU WASM Clippy, the GPU WASM release build and browser bindgen conversion passed. The first workspace run failed one GPU surface-budget assertion that still expected the former 96-byte view uniform. The assertion now derives its expected size from `VIEW_UNIFORM_BYTES` (160 bytes); the failed log and passing rerun are both retained. The explicit 256 MiB cap remains unchanged.

The shader still ignores saved UV, material and render settings. The probe does not compose multiple subtools or own the studio's live brushes, history, CPU fallback or device recovery. The normal browser's sustained 60/120-second responsiveness gates remain failed or unverified.
