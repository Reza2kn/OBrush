# C170: repeated ordinary Brush dabs with refreshed picked normal

This follows [the C169 one-dab alpha comparison](SCULPTGL_BRUSH_ALPHA_PAIR_C169.md). Its failed second-dab trial supplied SculptGL a fixed `(0,0,1)` normal but let OBrush refresh the normal after the first deformation. C170 gives both paths a refreshed normal on the same independently authored open triangle, first without raster alpha and then with the exact imported C168 alpha bytes.

The fixture has vertices `(-0.5,-0.25,0)`, `(0.5,-0.25,0)`, `(0,0.5,0)` and one oriented triangle. Both dabs select all three unmasked vertices with center `(0,0,0)`, squared radius `2`, intensity `0.25`, accumulate enabled, and no fold guard. The pinned SculptGL browser calls its actual ordinary `Brush.brush` method. After dab one, the probe recomputes the sole raw face normal from the current Float32 positions using the reference mesh's face-normal formula, writes that same raw normal into its three vertex-normal slots, and calls the runtime's `Picking.computePickedNormal()` before dab two. The refreshed raw face normal is `(0,-0.001552419736981392,0.75)` and the resulting picked normal is `(0,-0.002069888548472407,0.9999978577784039)`. Alpha sampling is disabled for this pair.

The shared Rust `SourceGeometryStroke` runs two accumulated dabs with the same pass and parameters, carrying forward the returned `SourceGeometryNormalState`. The regression compares all nine Float32 position words after **each** dab with the independent reference output. Both comparisons match exactly. The reference first-dab words are `[bf000000,be800000,3cef4a3b,3f000000,be800000,3cef4a3b,00000000,3f000000,3cfc01e4]`; second-dab words are `[bf000000,be8007eb,3d6f337a,3f000000,be8007eb,3d6f337a,00000000,3efff7a9,3d7be9c2]` (hex f32 bits, XYZ order).
