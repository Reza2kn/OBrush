# C137 mask-weighted rotation and uniform scale

The optional **Respect vertex masks** transform now covers numeric world XYZ rotation and positive uniform scale as well as translation. Each selected vertex commits `old_world + unprotected_weight × (full_world_transform(old_world) − old_world)` through the same shared Rust core used by native and WASM. For imported posed parts, OBrush converts the weighted result back into local coordinates without discarding the source affine matrix. The interaction center follows the full world transform, as in the pinned SculptGL `Transform.applyEditMatrix()` source. The selected group still commits as one atomic Undo entry.

An independent Rust test uses the two-part AFFINE SGL fixture, a nonzero world pivot, `(7°, −3°, 5°)` XYZ rotation, `1.05` scale and `(0.02, −0.015, 0.01)` translation. It calculates the world transform separately from the OBrush implementation and checks each masked vertex, the interaction center, unchanged source mask/face/pose fields, protected-point bit identity and exact project Undo/Redo. A normal browser run uses the visible numeric controls on an independently generated two-part sphere scene, selects both parts, and verifies the saved mesh with an independent JavaScript scalar rotation oracle. Its maximum point-component difference is approximately `2.3e-7`; 76 fully protected points remain exact, 380 partially protected points are present and 456 points change. All twelve browser transform workflows pass, including the previous mask-weighted translation gizmo and legacy project checks. The exact parameters, artifact hashes and numerical result are in [the evidence](evidence/sculptgl-masked-affine-c137.json).

The first rebuilt-browser run passed every geometry/history case but failed its final diagnostic assertion: the harness accidentally required a console error rather than requiring zero console errors. Its failed result is retained under `.artifacts`; the corrected full run passed with no reported JS/GL errors and actual 4× MSAA. This work still does not establish pinned SculptGL runtime parity. Mask-weighted retained levels/layers/Morph Targets, nonuniform scale, rotation/scale gizmo handles, all-protected interaction-center behavior, native GUI input and sustained latency remain open. For non-translation masked edits, the core rejects collapsed faces but does not prove freedom from self-intersection or every orientation reversal on complex meshes.

Final source validation passed `cargo fmt --all --check`, workspace/all-target tests (**2,465 passed, zero failed, one ignored**), strict native and WASM Clippy, `scripts/build-web.sh`, `scripts/package-macos.sh` and deep/strict code-signature verification.
