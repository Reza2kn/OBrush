# C192 plane-handle browser coverage

This follow-up tests all three C191 plane pads through the ordinary OBrush browser, then tests Plane Z on two selected, partly masked meshes. It changes the browser verification harness rather than the shared geometry or renderer. The pinned SculptGL source remains commit `8e45dafc0f7906e5238dfffc1a2df742bd25f29d`; its `src/editing/Gizmo.js` uses projected-pivot pointer offset and a ray intersection with the selected world plane. The source file SHA-256 is `e56a6e70f0eb2d53dd30240aa8a93c16258a3605b0a885aab743b6cb07df3c6c`.

An owned, isolated Chrome run passed 20 transform workflows on the C191 production web build (served WASM SHA-256 `79da60cac68e6eab313dd295d0d4e5b9a0637f31ebe49d306d78c475f789d1cc`). On the independently authored 266-point active fixture, the three browser drags previewed `[0, -0.12476348876953125, -1.7775163650512695]` on Plane X, `[0.0870506763458252, 0, -1.0583782196044922]` on Plane Y, and `[0.215165376663208, 0.1836179494857788, 0]` on Plane Z. Each prohibited axis was exactly zero. Held mesh buffers and document revision stayed unchanged, release made one edit, independent affine position arithmetic differed by at most `1.1920928955078125e-7`, and Undo/Redo recovered exact saved states.

The selected-group Plane Z gesture used a 4×3 px pull. Its preview moved both selected draw calls while preserving their buffers and document. Its displacement was `[0.033335208892822266, 0.025951385498046875, 0]`. After one shared-core commit, an independent per-vertex `old + (1-mask) × displacement` check had maximum component error `2.088928221510855e-7`; 76 fully protected vertices stayed exact, 380 partially protected vertices were present, and 456 vertices changed. Undo/Redo recovered exact saved states. The final run recorded no GL or JavaScript runtime errors. Its result is `.artifacts/transform-browser/plane-group-c192-small-4f94889c-85d4-45d9-b432-e443cce14cd1/result.json` (SHA-256 `0d54ec3e2628cf19684f4e639b67b5a56d054d3810aa5272c84d7db3bf3e2cdf`).

Two failed checks remain preserved. The first group run used a single-active-only preview assertion and failed even though both selected parts were supposed to preview; `.artifacts/transform-browser/plane-group-c192-fb9bdb3f-32df-4454-bbe3-47f6ef398b6c/result.json` has SHA-256 `d3d59d27d1ff4b9883245d97b1757ccc6355b1cc38712b8b71def0883b39ac51`. After correcting the assertion, the original 31×23 px masked group pull was rejected by the shared fold guard with `Mask-weighted transform would collapse or fold face 21`; the document stayed preserved and the harness rightly failed its expected-commit gate. That result is `.artifacts/transform-browser/plane-group-c192-corrected-11211faf-7655-4ec0-ae23-dfa26aa5ab0e/result.json` (SHA-256 `d9fa664b454f7928ad00125ddabcdd3149377bc98aed1808f8ab512a9b3fc504`). The accepted small-pull run keeps the original failures visible rather than treating the large pull as successful.

This covers one default camera and synthetic mouse gestures. Plane-pad behavior has not been paired with a physical pinned SculptGL browser run. Rotated/scaled selected groups, physical pen input, edge-on handle accessibility, retained-detail mask transport and sustained large-mesh latency remain open. These checks do not establish Transform-family, SculptGL or ZBrush parity.
