# Signed mask extraction (C70)

The existing mask extraction command accepted only positive outward thickness. C70 accepts the pinned SculptGL control range of **−5 to +5 world units**. Zero creates a single selected open patch; positive thickness retains the existing outward shell; negative thickness creates an inward shell with the original patch as its outward-facing skin. Boundary side winding is reversed for the inward case. All paths keep the source part intact and use the existing whole-scene history and validated append transaction.

The independently authored half-masked unit sheet (threshold 0.5) gives a 5-vertex/3-triangle open patch at zero. At thickness −0.125 it gives a closed 10-vertex/16-triangle shell with signed volume 0.0625. Position-plane and volume errors are zero on this fixture. Core checks also exercise closed full-mask spheres, both ±5 endpoints, malformed inputs, source preservation and redo on rejection. Full workspace testing passes 2,352 tests with one ignored; formatting, strict native/WASM Clippy, the official browser build and signed macOS package pass.

The owned Chrome workflow uses the visible numeric thickness field, creates both parts from a normal imported project, saves each `.obrush`, checks the visible GPU vertex/index buffers against the saved scene and verifies whole-project Undo/Redo. All nine mask-filter/extraction workflow cases pass on the final WASM build; 107 saved snapshots cover 124 visible GPU draw comparisons. The signed cases report exactly 5/3 and 10/16 output counts, zero coordinate-plane error, and 0.0625 inward signed volume. Browser runtime exceptions and console errors are zero; its owned Chrome and server exit cleanly. [The C70 evidence index](evidence/sculptgl-signed-mask-extract-c70-0.1.20.json) binds source, build, fixture, runtime and checks.

**This is not SculptGL extraction parity.** The pinned [SculptGL Masking.js source](https://github.com/stephomi/sculptgl/blob/8e45dafc0f7906e5238dfffc1a2df742bd25f29d/src/editing/tools/Masking.js#L187) selects whole incident faces from mask-qualified vertices; OBrush clips triangles at an interpolated threshold. The reference also smooths a nonzero shell border three times and applies a small signed offset before thickness. Those differences affect the same unit sheet and have not been quantified by a paired browser reference run. Large signed thickness can be rejected by OBrush's orientation/precision guards even though the control admits the numeric value. Native GUI, physical input, a full reference image/geometry comparison and long-session performance remain unverified.
