# C118: checked sparse GPU-result document commit

The shared Rust core now accepts sorted, unique 20-byte records containing a little-endian `u32` vertex ID and RGBA32F local position. The ordinary versioned OBrush document remains authoritative. The same captured subtool, pose, complete source-mesh fingerprint, open-edit and redo checks run before mutation; finite coordinates, the fourth position word, protected masks, surface fold guard, candidate validation and one undoable replacement remain required. Bad byte lengths, duplicate/out-of-order/out-of-range IDs and invalid coordinates reject without changing the project.

On the independently generated 162-vertex sphere from C117, the browser's isolated WebGPU point program changed vertex IDs `[25,84,85,88,89,147,149]`. The 140-byte sparse record payload and the 2,592-byte full position buffer produced the same complete accepted `.obrush` bytes (SHA-256 `78ee164193035562df3690cd6c399dd9a1f8fa8c1aefc132eb986a86d4cc47c5`). Invalid and repeated stale sparse results rejected, Undo and Redo restored exact project strings, and both offscreen and visible canvas frames changed. Native and browser full GPU positions remained byte-identical (SHA-256 `602ae3297642001c1249fb6d953b8c7b4bcf87eb69897410d8df826ac2d20337`). The browser recorded no exceptions, console errors or external requests; its owned process exited zero and server closed.

The browser comparison **still reads back all 2,592 GPU position bytes**, then builds the 140-byte records in JavaScript. It proves the core/WASM sparse transaction and output equivalence, **not** lower GPU transfer, brush latency or SculptGL responsiveness. A GPU-owned changed-row compaction/readback and normal-studio integration remain required before measuring a sparse performance benefit. This point program also does not implement a reference SculptGL brush.

`cargo fmt --all -- --check`, full workspace/all-target tests, strict native workspace Clippy, strict core/GPU WASM Clippy, a final GPU WASM release build with `wasm-bindgen` 0.2.129, and the final owned-browser replay passed.
