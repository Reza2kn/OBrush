# Source Worker validated retained decode: proposed trial

**Status:** design only; no product edit, build, or browser run authorized for this isolated trial. Base is integrated `6e108d2`. The prior direct-decode candidate `1bd5424` was rejected and reverted in `2db3e1b`; its frozen 100k result SHA-256 is `2aac2ed760a474ab63930e950b2fb270ff4c6a0a8bb7d8990a9c2a2211d2225a`. It measured 155.6 ms retained decode against the fixed <120 ms target, with a 466.7 ms active RAF maximum and a late release-tail probe. The strict GPU saved-normal oracle failed at every state. Preserve this receipt; no result replacement or threshold change.

## Hypothesis and bounded change

`decode_source_worker_retained_warm` validates the public mesh before computing its mesh digest. `SourceGeometryNormalState::decode_warm` validates it again, then calls `seed`, which validates again. Seed's normal-storage check and fresh normal compute each validate a further time. The seed also computes a complete normal field and ordered tree which the packet immediately replaces. The previous direct-decode trial removed that seed work but left multiple public traversals and did not reach the browser target. The next candidate should make **one full public `Mesh::validate` call** at the packet boundary, with the Source mask-convention check at that boundary, and carry a private `ValidatedMesh<'a>` token holding `&'a Mesh` and checked counts into the retained decoder. Its lifetime must remain tied to the exact immutable borrow; no pointer-identity cache, unsafe lifetime extension, externally constructible token, or reusable validation flag is allowed. Public callers and fresh-seed APIs keep their existing validation behavior.

After this one validation, decode canonical original-face rows and original-to-triangle starts from the already checked mesh, enforce checked normal/state/operation budgets before allocating, and read the exact retained position/face-normal/vertex-normal/tree words. Keep the existing packet size/header/target/version/length/checksum/mesh-digest/state-fingerprint checks; finite and count checks; exact position-word binding; full `OrderedTree::decode_warm` ring/face-box/parent/child/free-list checks; final `matches_mesh` and approximate-byte cap; and caller revision/history publication checks. No packet, project, GPU, geometry, undo, or browser protocol change. A failure must leave the owning document and GPU unchanged. If a private count-only storage helper is introduced, accept only the validated token and preserve the same overflow and cap arithmetic as the public helper.

## Independent admission before browser

Use the same independently authored triangle and mixed triangle/quad meshes, including a branched retained tree, selected-refresh normals, and second/third future dabs. Compare baseline and candidate packet bytes, decoded state fingerprint, all position/face/vertex normal f32 words, tree rows and render-selected bits, then public Save/Undo/Redo. Reseal malformed packets to exercise nonfinite center/normals, bad surface tags, lengths/counts, topology/rings/bounds/links/free list, state fingerprint and trailing/truncated data. Use independent pre-decode mutations to prove that changed position bits, triangles or original surface faces reject at the mesh digest, and that malformed mask convention, masks, normals, colors, materials or UVs reject at full public validation. Valid changes to non-geometry attributes need not change the geometry-only packet digest; the host revision/scene-binding check must separately reject a scene edit made after Worker capture. Cover stale target/revision and over-budget mesh/packet as distinct cases. Keep parser errors atomic and allocation bounded. Run native/WASM focused tests, workspace tests, strict Clippy, formatting, and aligned web build. A matched same-mesh/same-packet 100k native/WASM decoder microbenchmark is diagnostic only.

## GPU normal oracle and browser decision

The frozen SP-WORKER-01 verifier compares active VBO normals to serialized `mesh.normals`. That is a known invalid Source-display oracle: imported Source metadata selects fresh static or retained selected-refresh normals, and private selected rows are not serialized. In the rejected run the Before GPU normal SHA-256 `02a0c38496e4147fc63cce3da0967a2c08975598ed1f25f38f83b6a6fc9f7461` exactly equals the independently reconstructed fresh-static Source normal oracle already recorded in `SOURCE_GPU_DISPLAY_NORMAL_ORACLE_PREREG.md`, while public Save normals differ. **Do not change or waive the frozen verifier**; preserve its failed saved-normal check.

Add a separate, read-only, bounded producer-to-VBO diagnostic at Before/After/Stable/Undo/Redo. After confirming object ID, render policy, mesh identity, selected-state generation and one active draw VBO, capture a SHA-256 of the normal f32 words selected from the document's retained producer (or fresh Source field when no retained state) and independently hash the actual WebGL VBO normal words through CDP. Capture position words against public Save and GL errors as before. At fresh-static Before and at Undo only if producer absence is proved, also require the independent Python original-face scalar normal oracle to match the VBO. For retained After/Stable/Redo, producer-to-VBO equality establishes publication consistency only; native scalar selected-refresh/history fixtures establish semantic correctness. A mismatched producer or VBO hash, ambiguous active buffer, absent state provenance, missing raw evidence, or failed native history fixture rejects. The frozen saved-normal failure remains explicitly failed even when this supplementary diagnostic passes. No SculptGL/ZBrush or SP-WORKER-01 full qualification follows from it.

Run one frozen ordinary-browser 100k Worker cohort only after a lane handoff, with the unmodified input schedule and verifier, exact fixture/protocol/build hashes and independent whole-file audit. A temporary read-only timer may report retained decode and separate scene/delta time, but its patch/build hash and nonpublication tests must be retained; remove it afterward. The fixed local performance target remains retained decode <120 ms, scene/delta <=373.6 ms, and total main-thread finish <=566.9 ms, without exceeding the existing RAF/release/pacing gates. Different delivered dab counts or packet sizes forbid causal speedup claims. Preserve every failed check and stop before 1m if any 100k gate fails. Promotion requires a separate root decision after the frozen failure and supplementary oracle are reported honestly.

## Risks

A token that is detached from its checked borrow could silently skip validation after mutation; keeping its field private and its lifetime tied to `&Mesh` is essential. Count-only budget extraction can accidentally reduce peak-scratch accounting. Building original-face rows directly can alter quad triangulation or row order. A producer hash may miss a semantic error shared by decoder and renderer, hence separate scalar/history tests. A candidate can improve decoder time while the release-tail or RAF maximum still fails, as in the prior run; no isolated substage win establishes real-time sculpting.
