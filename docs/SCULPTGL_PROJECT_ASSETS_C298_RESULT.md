# C298: durable project image assets

Contract: [preregistered fixtures and gates](SCULPTGL_PROJECT_ASSETS_C298_PREREG.md). This is a scoped OBrush project-format and browser-workflow result, not complete SculptGL or ZBrush parity.

The v8 `.obrush` schema stores canonical bottom-up RGBA8 pixels, dimensions and names for one UV image and up to four custom MatCaps, plus shading and selected MatCap index. Versions 1–7 still load without images. The core validates dimensions, base64 length/content, selections and aggregate memory before it changes a document. Limits: 2048 pixels per side and 16 MiB per image; 32 MiB for custom MatCaps; 48 MiB aggregate RGBA; existing 512 MiB JSON cap. Opening a project, importing/resetting an image and changing the asset view take part in Undo/Redo. The app checks the live GPU texture-size limit before replacing the scene.
