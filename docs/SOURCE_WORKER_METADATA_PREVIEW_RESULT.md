# Sparse imported Source preview candidate: scoped result

This implements the candidate in [the frozen preregistration](SOURCE_WORKER_METADATA_PREVIEW_PREREG.md). Admission is deliberately **stricter** than that preregistration: every other visible object must have no Source metadata. The active imported object must have identity affine, shader 0/PBR, matcap 0, full opacity and no alternate render effects. This restriction was added after review; the original preregistration remains unchanged. The route is still query-gated and off by default.

The checked sparse packet now carries separate public Mesh position/normal words and retained Source *display* normal words. The latter are chained against an independently captured starting display state; the former remain the final-publication witness. A missing or stale selected/static Source normal field rejects the preview. GPU gap fill and cancellation restore the captured display-normal baseline. The renderer checks the whole-mesh Source normal identity once per upload/restore, avoiding an accidental per-row whole-mesh check.
