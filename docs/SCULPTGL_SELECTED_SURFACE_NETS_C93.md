# Selected-mesh Surface Nets and Block remesh — C93

Two independently authored, overlapping colored/material boxes were imported as separate parts, selected in the same right-then-left order, and fused at resolution 16 in the pinned SculptGL browser and OBrush. Smooth Surface Nets and Block each produce 1,058 vertices, 1,056 quads and 2,112 split triangles. A bijective world-position mapping matches **all 1,056 oriented quads** in each mode. Native-core maximum/RMS world-position differences are `1.2529e-7`/`7.9362e-8` for Smooth Surface Nets and `1.7378e-7`/`8.4958e-8` for Block.

The first OBrush paired run had exact topology and material/mask values but RGB maximum difference `1.0`: nearest-surface triangle projection could not reproduce the reference's overlapping-source voxel color blend. Surface Nets and Block now share the sampled voxel attribute field and per-cell inverse-distance weighting already used by Marching Cubes. On the same fixture, all 3,174 mapped native RGB, 2,116 material scalars and 1,058 unmasked weights match the reference exactly in both modes. The older core output and mismatch receipts remain in `.artifacts`.

The isolated browser run imported and selected both parts through visible controls, used the selected-fusion button for each mode, and checked the saved scene against actual WebGL2 buffers and exact project undo/redo. Against the pinned reference, all oriented quads match. Maximum world-position differences are `1.4618e-7` (Smooth Surface Nets) and `1.8913e-7` (Block); maximum browser-save RGB and material differences are `2.706e-8` and `2.384e-8`, with exact unmasked weights. Existing one-mesh Smooth Surface Nets and Block browser workflows also passed save/GPU, quad OBJ interchange and history checks. The served WASM SHA-256 is `884e597f989be35b96919ed57de98bcc57c9747774fe88dfc5be26ee329c76c8`.

The shared-core selected-fusion test checks a low work-budget rejection without scene mutation, closed quad output, blended color and exact undo/redo. This fixture does not establish general remeshing parity: other resolutions/shapes, mixed UVs, selected affine/source-origin meshes, sustained performance and reference UI selection ergonomics remain unverified. The browser still computes geometry in WASM and draws with WebGL2; the WebGPU prototype remains separate.
