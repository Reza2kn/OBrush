Full-stroke public Before/After/Undo/Redo and active GPU observations were retained.

C329 resolves the C327 off-polarity contact-count confounder and shows a very close **scoped** Pinch geometry result. It does not pass its own calibration gate, establish full Pinch parity, or close the wider SculptGL/ZBrush parity rows. A new, independently frozen calibration study would need to distinguish actual ray displacement from reference Float32 pick-report precision before revising that gate. No product geometry change is justified by these captures.
