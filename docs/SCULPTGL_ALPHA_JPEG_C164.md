# C164: bounded JPEG brush alpha and per-tool browser workflow

The browser and desktop alpha picker now accept PNG and JPEG. Both routes send original file bytes to the same bounded Rust decoder; the browser does not use Canvas2D to decode an import. The JPEG path reads dimensions before allocating a pixel image, rejects sides above 1024 and encoded input above 16 MiB, applies the decoder's allocation limit, and converts the result to top-down RGBA. Existing PNG behavior and the request-ID check before decoding remain intact. This is an `obrush-app` input boundary; geometry, file IO and history still run through the shared `obrush-core` document.

The independent fixture `crates/obrush-app/tests/fixtures/independent-gray-bands16x16.jpg` was encoded with Pillow 12.3.0 from two constant grayscale bands, 64 and 192, at quality 100 with no chroma subsampling; SHA-256 `0edf90c34f0d33c65d63fc6a9a70b7c191a53abe0c10435e5303ce01c288b9e0`. Native unit checks decode all 256 pixels to the two expected opaque RGBA values, and the existing SculptGL Mean RGB conversion retains 64/192. Truncated files and a header modified to declare 1025 pixels reject. This numerical oracle covers this grayscale fixture, not arbitrary JPEG encodings or reference brush mathematics.

The owned normal Chrome run imported the JPEG through the visible alpha picker with Mean RGB selected. The picker bound request 1 to Draw, created one 16×16 library entry, and the ordinary Draw stroke advanced the document revision from 1 to 2. The clipped viewport PNG changed from `8259e213d90c586b07ba9555d45f60972ff4b9493857c1261a9bd29c25883b8d` to `482f2ffbebc201ec2b9104d4b1a70dc402da8d77114e465d5d8b51c1fec99380`; actual keyboard Undo and Redo reproduced those exact hashes. In the same browser session, choosing Square gave Draw a 64×64 independent preset, Clay retained None, returning to Draw retained Square, then Skin selected and None cleared it. These are workflow checks, not claims that the generated Square/Skin bitmap values match SculptGL's bundled JPEG assets.

The pinned SculptGL source uses an `image.*` file input and browser image loading, then converts raster RGB to an alpha. This change closes the missing JPEG *input route* for a bounded PNG/JPEG subset. SculptGL's broader browser-decodable `image.*` range, exact imported-raster filtering and mapping, reference Square/Skin asset appearance, all-tool response matrix, native GUI import, and full reference parity remain open.
