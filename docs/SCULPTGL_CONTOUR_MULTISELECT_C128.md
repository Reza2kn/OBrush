# C128: combined contour for multiple selected parts

The independently authored two-quad SGL from [C127](SCULPTGL_CONTOUR_OCCLUSION_C127.md) has a smaller rear quad wholly inside a larger opaque front quad. Import selects the rear part. This check then adds the front part to selection in both pinned SculptGL `8e45dafc0f7906e5238dfffc1a2df742bd25f29d` and the frozen C126 OBrush browser build. The reference harness calls its `setOrUnsetMesh(front, true)` selection method directly, the same method reached by its Shift-select sculpt/transform paths, without issuing a sculpt dab. The OBrush harness Ctrl-clicks the first part in the normal scene panel and uses its normal contour checkbox. Selection ends as both parts in both browsers.

At matched 1140×825 viewport crops, the contour off/on response is the **outer combined silhouette only**. The pinned source changes 4,808 RGB pixels in a 600×601 box; OBrush changes 4,800 in a 600×599 box. Direct changed-pixel mask IoU is `0.6013333333` because adjacent edge samples land on different pixels, but **100% of each mask's changed pixels lie within one pixel of the other's**. The earlier rear-only contour changed 3,208/3,200 pixels in an inner box, so this run confirms that adding the front selection changes the outlined region rather than retaining the rear outline. It does not establish exact contour color, alpha or sample parity.

The OBrush scene-panel selection is `[2,1]`; its normal checkbox off/on/off preserves the exact 3,730-byte saved project SHA-256 `ee02be41506c6da3138f1eee7b461b81aeac6f53649331e16ae22195340b6eb6`. Its before and after-off viewport crops are RGB-identical. Both browser runs report zero console errors, exceptions, blocked external requests and cleanup errors. The unchanged OBrush app WASM is SHA-256 `5c78d1ce06ee2fcaf017d888c00c24299dcc634eb0779abcebb538134ec3918f`.

The source used its actual selection method but not a physical Shift-click. A retained physical Shift-click attempt with its Transform tool at viewport point `(300,190)` did **not** add the front object: source picking reported no hit at canvas point `(300,150)`, and selection stayed `[1]`. The attempt's failed result is `.artifacts/contour-multiselect-c128/source-ui-1792282902995/result.json`; it is not counted as a passing source UI check. The successful comparison covers two nested planar parts at DPR=1, not arbitrary overlapping shapes, three-part membership toggles, downstream duplicate/delete/isolate/transform/export selection scope, physical high-DPI, native GUI or sustained performance. The [machine-readable evidence](evidence/sculptgl-contour-multiselect-c128.json) binds the fixture, browser runs, images and measurements. Raw scripts, screenshots and logs remain in ignored `.artifacts/contour-multiselect-c128/`.
