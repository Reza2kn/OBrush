# C108: first static Reverse level

OBrush's `Reverse` command now recovers one lower static subdivision level from a mesh with no retained hierarchy. It runs in the shared Rust core, validates the candidate before replacing the document, and records one undo transaction. The original fine positions, colors, masks and materials stay attached to their physical vertices when the user navigates back to the fine level. UV coordinate IDs and corners must be exactly representable in the versioned stack; otherwise the command rejects the mesh without consuming undo/redo. The browser button is disabled when a retained hierarchy already exists.

The [paired comparison receipt](evidence/sculptgl-reverse-c108.json) records source hashes, oriented face matching and exact distances. The paired fixture is `crates/obrush-core/tests/fixtures/independent-reverse-quad.json`: nine independently authored points and four quads forming one recoverable coarse quad, with default Reverse settings and no brush stroke. The pinned SculptGL kernel is SHA-256 `79b24bf6e1818cbb468c53cfe49783de419fd3e58f72b220aeb9308932e47600`. The independently launched reference result is in `.artifacts/sculptgl-reference-runtime/reverse-c108-recheck-7263d272-e48c-4481-bc04-3bf89f3d3e33/result.json`; the OBrush browser result is in `.artifacts/sculptgl-paint-static-runtime/reverse-c108-recheck-974770bf-c60b-42c9-8063-fb8ae7c32a2d/result.json`, built from WASM SHA-256 `22f1678f4bacd0e22867f661690be718f4c1eb9946660c9136cc2cae44552940`. The matched coarse surface has four identical physical points and one identical oriented quad. Raising to the fine level gives nine identical physical points and four identical oriented quads. All compared coordinate differences are exactly zero for this integer-valued fixture; cyclic face rotations and vertex renumbering are ignored, but winding is not.

The OBrush browser run exercises the visible Reverse control, lower/higher navigation, complete save/GPU agreement, exact undo/redo and project reload. A nonproduct tetrahedron is rejected and leaves the saved document unchanged. Core tests additionally check triangle, quad and mixed-pyramid fixtures and an unrepresentable fine-UV-ID rejection that preserves redo. The first browser attempt failed only its error-message oracle because it read the message after Save had replaced it; the failed receipt is retained at `.artifacts/sculptgl-paint-static-runtime/reverse-c108-33823e1e-778f-4348-a26a-1096d86bcaf7/result.json`. The first reference attempt tried a nonexistent `Higher` button after a successful Reverse; its failed receipt is retained at `.artifacts/sculptgl-reference-runtime/reverse-c108-e7debf49-da4a-4be4-84cf-0aa73ce7e155/result.json`. The corrected reference run changes the resolution with its normal numeric control.

This is a scoped first-level result. Reversing an already retained stack, arbitrary imported topology, noninteger coordinates, UV seams/aliases beyond the representable case, paired channel values, performance and full SculptGL/ZBrush parity remain unverified. The delivered browser path still performs shared Rust geometry in WASM and draws with WebGL2; this work does not change the million-vertex responsiveness result.

Validation: `cargo fmt --all -- --check`, all 2,405 workspace tests, strict native and WASM all-target Clippy, WASM workspace check, `scripts/build-web.sh`, and `scripts/package-macos.sh` passed. The normal browser run used the rebuilt WASM and completed its owned Chrome/server cleanup. These checks establish the scoped implementation and fixtures, not a general speed or feature-parity result.
