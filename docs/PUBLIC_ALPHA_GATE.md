# Public alpha release gate (2026-10-20)

**Decision: hold a broad public download today.** OBrush is an experimental, independently written Rust sculpting studio with a native macOS app and a static WASM/WebGL2 browser build. Call any early release an **alpha for testing and feedback**, not a SculptGL or ZBrush replacement or a feature-parity release. The [317-ID SculptGL ledger](SCULPTGL_CURRENT_LEDGER.md) currently has 77 active workflows with scoped evidence and **zero closed full active gates**; the ZBrush target has much larger explicit gaps in [FEATURE_PARITY.md](FEATURE_PARITY.md). `python3 scripts/audit-sculptgl-inventory.py --check` passes at this audit.

## What is ready, and what is not

- Source is dual MIT/Apache-2.0 licensed with bundled dependency notices. [README.md](../README.md) documents local macOS packaging and localhost browser builds. `scripts/package-macos.sh` builds an arm64 host app and ad-hoc signs it for local use; it does not produce a Developer ID signed/notarized public installer. The present `.artifacts/OBrush.app` passes `codesign --verify --deep --strict`; its executable SHA-256 is `8dc4e14d400afbad61da81a796869f4feae4deaa692c0614b0c210a2ee6c2d18`. The present `web/dist/pkg/obrush_app_bg.wasm` SHA-256 is `f3f718d0fac0972ed90bf63cbf06e11b4a489ec0b1fee7a00a00fe9147dfc58a`. These are **local artifacts**, not a final release build or clean-machine installation proof. Windows/Linux execution and physical tablet delivery remain unverified.
- A [packaged native consumer smoke](NATIVE_UI_SMOKE_2026_10_20.md) made one Draw edit on a fresh 40,962-vertex sphere, then recovered byte-exact public Undo/Redo and project reopen/save. Browser checks cover many smaller, scoped workflows and malformed asset rejection, including a [v8 project image round trip](SCULPTGL_PROJECT_ASSETS_C298_RESULT.md). This is evidence for an early testable foundation, not for all brushes or long sessions.
- Current user-visible quality blockers are **repeated in-place Draw saturation** and **jagged/low-poly degradation in a worked area**, plus the earlier triangular Move complaint. The [Q02/Q06 Move reports](NATIVE_MOVE_CLOSEUP_Q06_RESULT.md) found a local face-quality minimum near 0.1 and adjacent folds up to 50.26°; the paired close-up camera gate failed. The [B02 Move correction](NATIVE_MOVE_GUARD_B02_RESULT.md) bounded folds in one repeated small-grab browser fixture with exact history, but its modest mark does not settle the user's broader visual complaint. A [closer Crease comparison](SCULPTGL_CREASE_OVERLAP_CR02_REPORT.md) showed continuous grooves and exact history on one independent sphere, but its frozen camera/trace/pressure premises failed; repeated Crease on worked meshes remains open. Neither isolated mesh validity nor a smooth full-sphere screenshot settles these complaints.
- Dense browser sculpting is not real-time: the [fresh ordinary million-vertex run](SCULPTGL_MILLION_RELEASE_ORIGIN_MRP11_REPORT.md) passed 17 file/history/shape checks but failed all four responsiveness gates (RAF P95 133.4 ms, RAF max 1,316.6 ms, app CPU P95 134.2 ms, release acknowledgment 394.38 ms). The optional Worker path is not the ordinary brush path. Browser reload/close loses unsaved work; [README.md](../README.md) documents that autosave/recovery is not implemented.

## Must pass before a broad public alpha

1. **Worked-surface quality:** on fresh and previously worked independent meshes, record normal-path browser and packaged-native Draw, Crease, and Move sessions with exact settings/input traces and original-resolution close-ups. Include at least 100 repeated/in-place Draw dabs, overlapping strokes, the default 0.180/35% Crease, and small-radius 0.037/79% X-symmetric Move. Freeze objective geometry/visual thresholds before rerunning; require no new inverted/degenerate faces, no visibly torn or sharp triangular artifacts in a reviewed close-up, and an intentional, explained response when a safety limit prevents more deformation. Save full Before/After/Stable/Undo/Redo projects and verify exact history. Do not substitute a test of a single fresh sphere for worked-area behavior.
2. **Final-artifact consumer smoke:** bind one release commit to official `scripts/build-web.sh` and `scripts/package-macos.sh` outputs and their hashes; run fmt, full workspace tests, strict native/WASM Clippy, inventory audit, and a clean-profile browser plus packaged macOS startup. Through visible controls, create/import, sculpt, save, reopen, undo/redo, reject malformed/oversized files without replacing the document, and continue sculpting. Retain failures and screenshots. Include a sustained 15–30 minute 10k–100k-vertex session with no post-release ghost dabs or unrecoverable UI stall. A million-vertex pass is not required if the limitation is plainly stated and capacity/UI limits prevent a misleading promise.
3. **Safe distribution:** provide an actual versioned browser URL and/or a downloadable macOS package with the exact commit, binary hashes, dependency notices, supported OS/browser requirements, and a clean-machine install/open check. If distributing the app beyond source builders, sign/notarize it or document the exact macOS security prompt and supported installation route. Warn before discarding unsaved browser work, exercise the save/download path, and state clearly that crash recovery/autosave are absent.
4. **Feedback intake:** add a visible link to a public GitHub **Discussions / Ideas** category where users can vote with reactions, and a GitHub **Issues / Bug report** template asking for version/build hash, platform/browser/GPU, tool/radius/strength/pressure/symmetry, fresh versus imported mesh, precise steps, screenshot and optional `.obrush` project. Mark proposed features separately from verified behavior; maintain a short public list of confirmed bugs, known limits and next priorities. Do not collect uploads or telemetry automatically.

For a smaller **source-build preview to invited testers**, the clean-machine binary and hosted-site requirements can be replaced by reproducible local build steps and an explicit experimental warning. The worked-surface repros, saved-work warning and honest limitation list still apply. Public copy should say “open-source sculpting alpha; useful core workflows; rough edges and incomplete compatibility,” and specifically avoid a percentage-to-parity claim.
