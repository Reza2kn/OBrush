# Public alpha release gate (2026-10-20)

**Release direction: open public alpha from day one.** OBrush is an experimental, independently written Rust sculpting studio with a native macOS app and a static WASM/WebGL2 browser build. Publish it as an **alpha for everyone to try and improve**, with known bugs in plain view. This is not a SculptGL or ZBrush feature-parity release. The [317-ID SculptGL ledger](SCULPTGL_CURRENT_LEDGER.md) currently has 77 active workflows with scoped evidence and **zero closed full active gates**; the ZBrush target has much larger explicit gaps in [FEATURE_PARITY.md](FEATURE_PARITY.md). `python3 scripts/audit-sculptgl-inventory.py --check` passed at this audit. The public-facing [alpha announcement and support matrix](PUBLIC_ALPHA.md) is the draft release copy.

## What is ready, and what is not

- Source is dual MIT/Apache-2.0 licensed with bundled dependency notices. [README.md](../README.md) documents local macOS packaging and localhost browser builds. `scripts/package-macos.sh` builds an arm64 host app and ad-hoc signs it for local use; it does not produce a Developer ID signed/notarized public installer. The current root-local executable SHA-256 is `a11ca58f392dbce5963eb1e5eb0076c51fc2c171808d2838671f10077e92d894`; the current portable `web/dist/pkg/obrush_app_bg.wasm` SHA-256 is `5719040ac5ed8e6331942dfd62a7452ee712959807ed659da9b4e0f931bd2141`. These are **local artifacts**, not a public release or clean-machine installation proof. Windows/Linux execution and physical tablet delivery remain unverified.
- A [packaged native consumer smoke](NATIVE_UI_SMOKE_2026_10_20.md) made one Draw edit on a fresh 40,962-vertex sphere, then recovered byte-exact public Undo/Redo and project reopen/save. Browser checks cover many smaller, scoped workflows and malformed asset rejection, including a [v8 project image round trip](SCULPTGL_PROJECT_ASSETS_C298_RESULT.md). This is evidence for an early testable foundation, not for all brushes or long sessions.
- Current **high-priority known quality bugs** are repeated in-place Draw saturation and jagged/low-poly degradation in a worked area, plus the earlier triangular Move complaint. The [Q02/Q06 Move reports](NATIVE_MOVE_CLOSEUP_Q06_RESULT.md) found a local face-quality minimum near 0.1 and adjacent folds up to 50.26°; the paired close-up camera gate failed. The [B02 Move correction](NATIVE_MOVE_GUARD_B02_RESULT.md) bounded folds in one repeated small-grab browser fixture with exact history, but its modest mark does not settle the user's broader visual complaint. A [closer Crease comparison](SCULPTGL_CREASE_OVERLAP_CR02_REPORT.md) showed continuous grooves and exact history on one independent sphere, but its frozen camera/trace/pressure premises failed; repeated Crease on worked meshes remains open. These issues may be disclosed in the public alpha; they must not be advertised as fixed.
- The repeated-Draw [stationary build gate](DRAW_STATIONARY_BUILD_GATE.md) reproduces the plateau on a fresh 40,962-vertex sphere: after 96 same-point dabs the baseline stops changing, and its picked height at dab 128 equals dab 256. Tangent-only fairing and two bounded local-salvage trials still plateau; none was shipped. A fix must continue useful growth without relaxing face-quality and fold guards or creating another sharp-triangle failure.
- Dense browser sculpting is not real-time: the [fresh ordinary million-vertex run](SCULPTGL_MILLION_RELEASE_ORIGIN_MRP11_REPORT.md) passed 17 file/history/shape checks but failed all four responsiveness gates (RAF P95 133.4 ms, RAF max 1,316.6 ms, app CPU P95 134.2 ms, release acknowledgment 394.38 ms). The optional Worker path is not the ordinary brush path. Browser reload/close loses unsaved work; [README.md](../README.md) documents that autosave/recovery is not implemented.

## Required for a usable public alpha package

1. **Reproducible build and download:** bind the published commit to official `scripts/build-web.sh` and `scripts/package-macos.sh` artifacts and hashes; run fmt, full workspace tests, strict native/WASM Clippy and the inventory audit. Publish an actual versioned browser URL and/or downloadable macOS package with dependency notices, supported systems, exact hashes and working install/open instructions. A macOS binary needs a clean-machine open check and either notarization or an accurately documented Gatekeeper route. Source build instructions alone are also public, but should not be described as a ready-to-install app.
2. **Basic consumer safety:** on the final published artifacts, use visible controls to create/import, make an ordinary edit, save, reopen, Undo/Redo, reject a malformed file without replacing the document, and continue working. Retain a clean-profile browser and packaged macOS startup receipt and any failed checks. Show a clear save reminder before a browser reload/close discards unsaved work; state that autosave and crash recovery are absent. These are data-safety and usability checks, not parity requirements.
3. **Open feedback:** link the public repository's GitHub **Issues / Bug report** and **Discussions / Ideas** from the release page and README. Issues should request version/build hash, platform/browser/GPU, tool/radius/strength/pressure/symmetry, fresh versus imported mesh, reproduction steps, screenshot and optional `.obrush` project. Ideas can be voted on with reactions. Keep confirmed bugs and proposed features separate; do not collect files or telemetry automatically.

## High-priority quality acceptance after or alongside publication

On fresh and previously worked independent meshes, record ordinary browser and packaged-native Draw, Crease and Move sessions with exact settings/input traces and original-resolution close-ups. Include at least 100 repeated/in-place Draw dabs, overlapping strokes, default 0.180/35% Crease and 0.037/79% X-symmetric Move. Freeze geometry/visual thresholds before testing; require useful repeated Draw response, no new inverted/degenerate faces, no visibly torn/sharp triangular artifacts in reviewed close-ups, and explicit behavior when a safety limit blocks a dab. Save Before/After/Stable/Undo/Redo projects and verify exact history. Also qualify a sustained 15–30 minute 10k–100k-vertex session with no ghost dabs or unrecoverable UI stall. Until these pass, publish them as known alpha bugs and do not imply they are solved. Million-vertex responsiveness is a disclosed limitation, not a prerequisite for an honest alpha. No percentage-to-parity claim is justified.
