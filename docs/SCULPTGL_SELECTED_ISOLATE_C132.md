# C132: selected-group Isolate and Show all

The OBrush scene panel previously offered Solo, which displayed only its active part even when several parts were selected. The shared Rust `Document` now has `isolate_selected_subtools` and `show_all_subtools`. Isolation hides every unselected part while preserving selected parts' own visibility; Show all makes every part visible. Each operation validates and commits one complete scene-history entry. The normal browser panel exposes both actions. Solo remains available as a separate OBrush view control.

The independent three closed-box SGL fixture has SHA-256 `939110d73dec934f0af70fb5c364eeb18f3ce18608449fe76804896c50c9c0ae`. In pinned SculptGL revision `8e45dafc0f7906e5238dfffc1a2df742bd25f29d`, physical Shift-clicks end at selected indices `[2,1]`. Its `GuiScene.showHide(true)` leaves box visibility `[false,true,true]`; Undo yields `[true,true,true]`, Redo restores `[false,true,true]`, Show all yields `[true,true,true]`, and Undo restores `[false,true,true]`. The reference harness invoked the GUI handler after physical selection; it did not physically click the checkbox.

The normal OBrush browser imports the same fixture and ends scene-panel Ctrl-clicks at selected IDs `[3,2]`. Its visible Isolate selected and Show all buttons produce the same visibility sequence. Saved `.obrush` project SHA-256 moves from `1159d48c65b426d5f407bf4085567d1b00dc8c65da38442e958e4b3e3206f0bd` (7,778 bytes) to `ca3f1b420f5addb03d83cf19f995a4ca77f72592c611fd711444e7fdf2b5d083` (7,779 bytes), then back. Ordinary Undo/Redo recover those exact hashes. A fixed 990×700 browser viewport crop changes PNG SHA-256 from `0119d585060344fb152e94ea977a7802201e3cad5f5194299f0ef7935c28339b` to `cb005d8f5968b7f36674353eb21fd1f7a038fd8a5dbf5463bc08b1f416127bc9` when isolated; its original and isolated screenshot hashes each recover exactly through Undo/Redo. The final tested browser WASM SHA-256 is `5bf3c99972b31a86da258f95d9777aa7b2eb15af6e209bda81b618f917b2bfe7`.

The shared-core test covers complete project history, mixed prehidden parts, and transition from OBrush Solo to selected-group isolation. A second normal browser run physically opens Preferences, selects the SculptGL basic shortcut profile, closes Preferences, then sends actual `I`, `I`, `Ctrl+D`, `Ctrl+Z` twice, `Delete`, and `Ctrl+Z`. The two `I` presses hide and show the unselected part; `Ctrl+D` yields five parts and two Undos restore the exact three-part project; Delete leaves one part and Undo restores the same project hash. The first keyboard attempt reached the duplicated scene but its diagnostic project capture was rejected on a redo branch. The corrected run used the normal Save project button, and both records are retained. Other meshes, picking hidden parts, mixed source visibility Undo semantics, translated button labels, native GUI and full SculptGL parity remain open.
