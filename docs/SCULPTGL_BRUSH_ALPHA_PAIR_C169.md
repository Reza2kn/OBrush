# C169: one controlled Brush dab with pinned raster alpha

An independently authored open triangle with vertices `(-0.5,-0.25,0)`, `(0.5,-0.25,0)`, and `(0,0.5,0)` was used to compare one ordinary Brush deformation. The raster alpha is the independently authored C168 16×16 PNG (SHA-256 `b4a27eb3696417e18d4972124fa62c5466a8a85eb2ef6d8be4a035abf3138f11`). The pinned SculptGL browser imported it through its actual alpha file input; the 256 decoded bytes have SHA-256 `d13e3ecbfb0f82d8b8c2be5a4d6c794626fee15a11508d1e9d7ca299ad715534`. The reference bundle SHA-256 is `79b24bf6e1818cbb468c53cfe49783de419fd3e58f72b220aeb9308932e47600`.

The reference diagnostic called the pinned runtime's actual ordinary `Brush.brush` method with a controlled three-vertex mesh, all unmasked, selected indices `[0,1,2]`, center `(0,0,0)`, normal `(0,0,1)`, squared radius `2`, intensity `0.25`, identity alpha frame, and accumulate enabled. This direct method call measures the kernel, **not** a normal UI stroke. Its first-dab output kept all X/Y f32 words unchanged and produced Z words `0x3c48d0de`, `0x3cb33b9e`, `0x3c6f28f3`. The corresponding decimal Z values are `0.01225682906806469`, `0.021879013627767563`, and `0.014597165398299694`. The owned reference receipt is `.artifacts/sculptgl-jpeg-alpha/8adacb9b-ea5d-486f-93ac-b43215c0da00/result.json` (SHA-256 `e924e4f42fa134fcfa040e6b4b518114485fdca8a2e545f117396e96f5089994`).

A shared-core Rust regression loads the exact 256-byte reference alpha output, applies one `SourceGeometryStroke` ordinary Brush dab to the same triangle and parameters with fold prevention off, and compares all nine position f32 words. All nine match exactly, including unchanged X/Y. This is a narrow kernel result under controlled picked face/normal and parameters. It does not establish matched pointer picking, spacing, pressure, symmetry, normal UI strokes, repeated-stroke response, dense-mesh quality, or sustained responsiveness.

The reference diagnostic also made a second direct `Brush.brush` call while retaining the explicitly supplied `(0,0,1)` normal. A trial comparison against a second OBrush full-stroke dab failed at the first vertex's X word (`0xbf0007ba` versus reference `0xbf000000`). OBrush refreshed its normal state after the first dab; the direct reference call did not. Those inputs are not equivalent, so the trial is preserved as `.artifacts/sculptgl-brush-pair-c169/failed-two-dab.json` and is **not** interpreted as a measured product divergence. A repeated-dab pair needs matched normal and picking updates in both runtimes.

The C168 normal-browser Source alpha import, visible sculpt and exact Undo/Redo remain the browser route evidence. C169 adds a direct reference-kernel versus shared-Rust geometry pair; it does not promote the frozen SculptGL inventory or ZBrush parity status.
