# C123: selected contour in the normal studio

This is a scoped implementation of `SGL-RENDER-CONTOUR` and its color control, **not a SculptGL parity result**. The pinned source revision is `8e45dafc0f7906e5238dfffc1a2df742bd25f29d`; `Scene.js` SHA-256 `092d17a08278700d6d85d3f8b9880e9152ce8c71be607fbe1584d0c5b5602f52`, `ShaderContour.js` `f897e1d572a060e9e26248bcf0727937b5974197f4c03856aa28c1aa80513b0d`, and `outline.glsl` `b6705d079b56101a07aad9945a61d86d1b48e9ba348cf2e14cc2a3ed5e300b4a`. The reference draws selected meshes into a no-depth mask and uses an eight-neighbor weighted Sobel magnitude with a 1.5 threshold. Its default display switch is off and default RGBA color is `[0.3, 0, 0, 1]`.

OBRush now draws selected mesh silhouettes to a separate bounded RGBA8 mask and composites the same Sobel edge expression over the ordinary GL/WebGL2 studio viewport. The mask is limited to 64 MiB and is released when the overlay is inactive. The localized Show contour checkbox and RGBA picker control the actual pass; modern SGL header import/export uses the current global contour flag. The color remains a view preference, as the SGL header carries only the switch. Geometry, selection, file data and undo history are untouched.

The final official browser build is frozen at `.artifacts/contour-c123/web-dist-final`, with app WASM SHA-256 `d3eb03b04458ee32c8cad1a639535dc7dc8f7d3a5e6372aaa8bf17f4f4ec6b48`. In the owned browser off/on/off run `.artifacts/contour-c123/probe-1792280384798`, the normal selected startup sphere gained a visible red silhouette: 4,684 RGB pixels changed in the central crop `(450,140,1130,800)`. Turning the control off restored all crop pixels exactly. In the separate actual picker run `.artifacts/contour-c123/color-probe-1792280393301`, full opacity produced summed absolute RGB difference `(204522,259857,255441)`, the UI-selected `0.49818182` alpha produced `(101762,129144,126993)`, and zero alpha produced `(0,0,0)`. All three states retained the same 5,317,105-byte saved project SHA-256 `2b88d59fc06ab6eed9ef25b51de267ff3791b00438e84a7d3247e1f651371fbb`. Both runs had zero browser exceptions, console errors or blocked external requests and recorded owned browser/server closure.

Final verification passed: `cargo fmt --all --check`, 2,457 workspace tests, strict native and WASM Clippy, `bash scripts/build-web.sh`, `bash scripts/package-macos.sh` and native package signature verification. An initial strict Clippy check caught a collapsible conditional after adding inactive-mask disposal; this was corrected before the final checks. The first color-probe attempt landed on a different scrolling position and did not toggle the checkbox; OCR located the real label in the corrected runs. An intermediate zero-alpha click at the edge yielded approximately `0.00727` rather than zero; the final left-end UI click yielded exact zero. These failed/intermediate browser records remain under `.artifacts/contour-c123`.

The reference composites its edge during its internal render pipeline, while this implementation composites over OBrush's finished view. Paired hosted-reference pixels, multi-selection and occluded-part behavior, transparent scenes, camera/DPR/resize matrix, native GUI appearance and precise color-space response remain open. This does not close the complete 317+5 SculptGL inventory, long-stroke performance or ZBrush parity.
