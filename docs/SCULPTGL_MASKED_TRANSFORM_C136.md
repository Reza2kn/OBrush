# C136 mask-weighted selected translation

OBRush now offers **Respect vertex masks** in the Transform panel. With this option enabled, numeric translation and the world-axis/free-plane translation gizmo commit each selected vertex by its unprotected mask weight in one shared-core transaction. The existing rigid shader preview remains visible during a drag. Protected vertices retain their exact coordinates; the selected parts, their source masks, affine poses and ordering remain intact. Undo and Redo restore the exact saved project. The default remains the earlier whole-part transform behavior.

The pinned SculptGL `Transform.js` at commit `8e45dafc0f7906e5238dfffc1a2df742bd25f29d` supplies the source formula: `Transform.end()` collects `getUnmaskedVertices()` for each selected mesh; `applyEditMatrix()` blends each old position with its edit-matrix result using the material blue channel as unprotected weight, then transforms the interaction center. This is a **source-code comparison**, not an instrumented SculptGL runtime match. OBrush maps its explicit mask convention to the same unprotected weight, converts world translation into each imported part's local affine frame, and rejects invalid/folded candidates atomically. Retained subdivision levels, layers and Morph Targets are explicitly rejected until their detail transport is matched. Mask-weighted rotation and scale remain unavailable.

The independently generated two-sphere browser fixture has two selected parts and patterned masks. A visible numeric `+0.025` world-X translation moved 456 points, preserved 76 fully protected points and produced a maximum component error of `2.675e-7` against `old + 0.025 × unprotected_weight`. A physical browser mouse drag on the world-X gizmo previewed both parts rigidly by `+0.03170299530029297` without changing GPU vertex buffers or document revisions; release changed the same 456 points with maximum component error `1.664e-7`, preserved the same 76 protected points, and completed one quiet history entry. Both paths recovered byte-identical saved projects on Undo/Redo. The complete rebuilt browser harness passed 11 transform workflows with no JS/GL errors and actual 4× MSAA. Its raw receipt and exact hashes are in [the evidence](evidence/sculptgl-masked-transform-c136.json).

Two intermediate harness attempts failed and remain under `.artifacts`: the first assumed non-active parts never receive shader preview, and the second assumed only the active part uploads after a group release. Both assumptions were wrong for a selected group; after correcting the harness, the complete run passed. These failures do not establish a product defect. The result is a scoped translation improvement, **not** SculptGL transform parity: no pinned reference runtime comparison, matched complex mask/affine cohort, retained-detail transport, masked rotation/scale, full gizmo handles, native GUI input, or sustained latency comparison has passed.
