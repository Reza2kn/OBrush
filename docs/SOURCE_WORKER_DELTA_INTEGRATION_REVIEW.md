# Static integration review of the isolated Source Worker delta trial

Review date: 2026-10-19. Isolated trial: `115186f` (`codex/worker-authoritative-source`); root observed clean at `ce0f0de`. This is a source/document review only. No Cargo build, browser run, merge, or new performance measurement was made. The old trial is not a production candidate.

## Integration decision

Do not cherry-pick `267677c` or `115186f` into root. The old branch modifies `crates/obrush-core/src/document.rs` to publish a private 88-byte-header, 28-byte-per-changed-row packet through `commit_source_worker_delta`; it adds `crates/obrush-app/src/source_geometry_worker_trial.rs` and the `web/source-geometry-resident-{input,worker}.js` one-shot API. Root has independently implemented the equivalent checked `OBRSDEL1` mesh-candidate codec in `crates/obrush-core/src/source_worker_delta.rs`, complete-scene and retained-state witness in `source_worker_cold_capture.rs`, ordinary opt-in held-pointer bridge in `crates/obrush-app/src/source_geometry_worker_host.rs` and `source_worker_held.rs`, shared worker geometry in `source_geometry_browser_worker.rs`, and `web/source-worker-held-input.js` / `web/source-geometry-worker.js`. The old document-level commit and persistent one-shot controller would bypass current preview, one-use history, retained normal, and ordinary input ownership boundaries. Its 100,000-vertex / 200,000-triangle admission cap also rejects the frozen 1m cohort.

The old `docs/SOURCE_WORKER_DELTA_TRIAL.md` remains useful as a historical transport diagnostic: on one frozen 99,602-vertex *native* Inflate contact, full result 18,940,554 bytes versus 122,476-byte delta for 4,371 rows (99.35% fewer result bytes). Its unoptimized native capture/apply/publication times were 1,332.794/1,757.383/1,590.432 ms. The separate three-vertex normal-browser audit passed public Save, two Undo/two Redo and GPU position/normal words, but it did not exercise the ordinary 60-second held pointer. These numbers must not be used as browser speedup or 1m evidence.

## Current blockers seen in root evidence

The current query-gated Worker is off by default (`web/index.html` requires `source-worker-held`). It has one outstanding Worker request at a time, drops intermediate input on release but still waits for an exact endpoint and `finish`, then executes checked final publication synchronously on the main thread. The frozen 100k release-timeline receipt (`docs/SOURCE_WORKER_RELEASE_TIMELINE_RESULT.md`) recorded endpoint reply at +15.2 ms, finish reply +211.8 ms, main commit +211.9 to +687.2 ms, and a matching approximately 481.5 ms RAF gap. At +102.4 ms the frozen queue predicate remained false because `finish` was pending. The old delta patch cannot remove this path: root already transfers a sparse final delta, while retained warm packet encoding/decoding and complete-scene witness dominate measured finish and publication stages (`docs/SOURCE_WORKER_FINISH_PACKET_PROFILE_RESULT.md`, `docs/SOURCE_WORKER_PUBLICATION_STAGES_RESULT.md`). An attempted fused warm encoder failed its frozen speed gate (`docs/SOURCE_WORKER_WARM_ENCODE_FUSION_RESULT.md`).

Root's frozen verifier also rejects raw public-mesh-normal versus GPU-normal words in five states. The current Source renderer may deliberately use a retained display-normal field distinct from public mesh normals. Before any admission claim, establish an independent canonical *edited-state display-normal* oracle and preserve the original frozen failure and protocol hash; do not silently replace the expected normal bytes or waive the gate. Stale scene/history, malformed or oversized delta/warm packets, Worker crash, and one-use ownership remain required rejection tests. A candidate that makes early public geometry visible during a gesture must prove atomic rollback and exact public Save/Undo/Redo, including retained state on the next stroke.

## Frozen production gate

Use `docs/SCULPTGL_WORKER_SUSTAINED_PROTOCOL.json` unchanged (SHA-256 `800641d09091e55df4618c5e76b97186f74e96ecf34872dd335e316e01cd7443`) and `scripts/verify-source-worker-sustained.py`. First validate exact build/served hashes and independently hashed SGL fixtures: 99,602 vertices / 199,200 triangles (`8f8d76f0d71e420a81358a0a44d3a4ffa2a3ac76e9221165e1359c8e720a7093`) and 999,002 vertices / 1,998,000 triangles (`dfb5316f62e392e633f03cb662dcb12215ed165a71a9ae72a3fd639528731afe`). Preserve failed runs.

For **each** cohort, use fresh owned browsers serially ordinary/Worker/Worker/ordinary on the same host and exact build. Import normally; use Source Draw/Brush row 0, 64 CSS px radius, intensity 0.25, no symmetry/pressure factors, documented orthographic Reset and Fit, a trusted pointer held 60 seconds over the prescribed ellipse with 24,000 requested moves at 400 Hz, then actual release. Record every requested/CDP-acknowledged/trusted-delivered move, coalesced/queued/applied/Worker-accepted dab and endpoint. The per-run gates are RAF P95 <=33.34 ms and max <=250 ms, app CPU P95 <=16.667 ms, release acknowledgement <=100 ms, complete released queue <=100 ms, pacing P99 lateness <=25 ms and max <=100 ms. Capture 2-second tail, bounded 1 Hz memory, Worker init/input/preview/final bytes and transfer lists, worker geometry/encode/finish CPU, and main seed/preview/witness/retained decode/publication/renderer CPU. Transfer-byte reductions alone are diagnostics.

At Before, After, Stable, Undo, Redo, independently audit complete public Save bytes and hashes, non-geometry attributes, topology, exactly one active WebGL VBO, position and normal f32 words, and Source display-normal semantics. Require Before=Undo, After=Stable=Redo, no new changed-face degenerates or orientation reversals, changed-edge stretch <=4, one history transaction, exact release endpoint, and no late edits after release. Retain malformed/stale/crash/cancellation receipts proving no partial public state, redo loss, or normal-state fork. Run `cargo fmt`, locked workspace tests, strict native/WASM Clippy, `scripts/build-web.sh`, `scripts/package-macos.sh`, and a normal-browser UI route on the candidate source; hash artifacts and record all failures. Only after **both** cohorts pass the unchanged frozen verifier and independent geometry/render audits may a worker responsiveness claim or default-route promotion be considered. Different delivered dab counts or a single browser pair cannot support an exact brush or causal speedup claim. SculptGL and ZBrush parity are separate feature-inventory decisions.
