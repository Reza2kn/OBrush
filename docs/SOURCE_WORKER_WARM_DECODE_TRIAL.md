# Warm retained Worker decode trial (preregistered)

This isolated trial starts at `43e2a1b` and changes only the retained warm codec and its focused tests. The query-gated 99,602-vertex SP-WORKER-01 baseline reported 171.0 ms in `decode_source_worker_retained_warm`, 373.6 ms in separate complete-scene witness/delta decode, and 566.9 ms total instrumented main-thread finish. Its frozen protocol SHA-256 is `800641d09091e55df4618c5e76b97186f74e96ecf34872dd335e316e01cd7443`, independent SGL fixture SHA-256 `8f8d76f0d71e420a81358a0a44d3a4ffa2a3ac76e9221165e1359c8e720a7093`, and retained browser result SHA-256 `42fb53ec181115b220699a6fe6d3bcef23616529f21055a7372f81d5fe7cce99`. This is one unpaired browser result; no target or threshold changes.

The decoder currently calls `SourceGeometryNormalState::seed(mesh)` before reading its warm payload. That computes a fresh complete normal field and builds a fresh ordered tree, then replaces both with the authenticated retained values. The candidate instead constructs only canonical immutable face rows and original-to-triangle rows from the validated public mesh, while decoding the exact position, normal and ordered-tree words once. It must preserve the seed path's checked normal/state/operation allocation bounds; the existing packet size, checksum, mesh digest, state fingerprint, finite checks, counts and full historical-tree validation remain mandatory. No new packet version, format change, hash shortcut or trust in unchecked private bytes is allowed. This candidate must not touch the separate scene/delta decoder.

Before browser admission, compare old and new decode results bit-for-bit on independently authored triangle and mixed triangle/quad meshes, including a warmed branched tree and subsequent second/third Source dabs. Check exact packet compatibility, selected-refresh normal words, tree words, render-selected bits and public Save/Undo/Redo after host publication. Resealed malformed packets must reject atomically for stale mesh/target, nonfinite normals/center, invalid lengths/counts, topology, rings, face boxes, parent/child/free-list defects, and state-fingerprint mismatch; allocation limits and truncated packets must remain bounded. A focused native/WASM 100k warm-packet benchmark should report old/new decode times on the same packet and mesh without calling browser/UI; this is only a codec substage diagnostic. Run `cargo fmt`, full workspace tests, strict native and WASM Clippy, and a fresh `scripts/build-web.sh` using aligned lockfile/bindgen versions.

Then run one frozen normal-browser 100k query-gated Worker cohort using the unmodified SP-WORKER-01 verifier. Capture product build hashes, applied dabs, retained decode and total main-thread finish times, RAF P95/max, app CPU P95, release tail, pacing, Worker finish round trip, errors, and complete public Before/After/Stable/Undo/Redo plus independent shape audit and GPU row words. Preserve all failures. The browser admission target is retained decode below 120 ms (at least 30% below 171.0 ms), without raising the separately timed scene/delta decode above its 373.6 ms baseline or total finish above 566.9 ms. All exact file/history/geometry/packet gates must pass, with no new GPU-word mismatch beyond the already documented edited-display-normal oracle limitation. A different delivered-dab count or packet size prevents a causal speed ratio. If a gate fails, reject and retain the candidate patch/receipt rather than promoting it. Even if this local target passes, frozen responsiveness and SculptGL/ZBrush parity stay open until their own gates pass.

## Result: rejected

The candidate at `1bd5424` passed focused tests, the full workspace suite, strict native/WASM Clippy, formatting, and a web build. On the same independently authored 98,306-vertex mesh and identical 9,772,680-byte packet (`BLAKE3 858a8cec…`), an ignored native debug diagnostic measured median 2,236.862 ms for the baseline decoder and 1,476.125 ms for the candidate. These are codec-only numbers, not browser responsiveness or a causal browser ratio. Candidate and baseline logs are retained as `.artifacts/swwd-candidate-native.log` and `.artifacts/swwd-baseline-native.log` in the isolated worktree.

The single frozen 100k ordinary-browser Worker receipt is `.artifacts/source-worker-sustained-spw01/100k-worker-ce54c37f-680b-4546-aea0-df5fd37aced9/` (result SHA-256 `2aac2ed760a474ab63930e950b2fb270ff4c6a0a8bb7d8990a9c2a2211d2225a`). It used the unmodified frozen runner and a temporary read-only retained-decode timer (patch SHA-256 `386959e3714c9f629034ab11e9b5bf45a802526ca1e1361293fc67d5cb8dabfe`, diagnostic WASM SHA-256 `e8d12ef88efe53c94acbf9e4caccfbf02b60b21e7e810d4ef8a7087ee3f43f27`). The timer patch was removed after measurement; no probe code was promoted.

The browser measured 155.6 ms retained decode, missing the fixed <120 ms gate. It delivered 1,288 dabs, so its 171.0 ms prior-result comparison is unpaired and is not a causal speed ratio. The full held commit took 465.7 ms and release-to-commit 682.3 ms; the separate scene/delta stage was not directly measured in this diagnostic. Active RAF P95 was 16.7 ms, but max was 466.7 ms. The independent shape audit passed. The unmodified verifier failed `active_raf_max_ms`, `queue_empty_by_100ms` (first tail probe was late), and `gpu_position_normal_all_states`; the GPU audit found exact position words but mismatched normal words in Before/After/Stable/Undo/Redo. Preserve the raw `audit.json`, `gpu-audit.json`, and `verify.json` in the receipt; their exit codes were 0, 1, and 1 respectively. This result cannot establish correctness or performance admission, regardless of any preexisting edited-normal oracle limitation.

The candidate was reverted by `2db3e1b`. Only this failure report remains for integration; the packet and browser receipt stay available for a later, separately preregistered investigation.
