# C167: transparent PNG alpha from pinned runtime to shared Rust

The independently authored `independent-hidden-rgb2x2.png` has top-down RGBA pixels `(255,0,0,0)`, `(0,255,0,128)`, `(0,0,255,255)` and `(255,255,255,64)`. OBrush's bounded PNG decoder correctly preserves those source bytes, including hidden red. Before C167, its SculptGL Mean RGB conversion produced `[85,85,85,255]`. The pinned SculptGL runtime, reached through its ordinary `#alphaopen` browser file-change route, produced `[0,85,85,255]`: Canvas2D readback loses RGB when opacity is zero. The separately named Legacy Weighted Opacity conversion remains unchanged.

The shared native/WASM brush-preference conversion now maps only fully transparent RGBA input to zero before calculating SculptGL Mean RGB. Partial transparency retains the mean-RGB value. Existing independent-fixture unit checks and the three import-host checks were corrected to the browser-measured rule; a two-pixel transparent/opaque red check preserves the distinct Legacy result `[0,77]` versus SculptGL-compatible `[0,85]`. The actual pinned browser import returned `[0,85,85,255]` and primary/mirror nearest-sampler values `[255,255,85,85,0]/255` and `[85,85,255,255,0]/255` at local X `[-0.75,-0.25,0.25,0.75,2]`. Reference result `.artifacts/sculptgl-jpeg-alpha/ae250458-e545-4b0d-8db1-b19bf9b6602d/result.json`, SHA-256 `83c6d8207f11233d5b48672c72aa427e8deade310e1dc89ea9a834193e44a624`.
