The [C329 contact/projection protocol](SCULPTGL_SOURCE_PINCH_C329_PREREG.md) was committed before this harness. `scripts/check-sculptgl-source-pinch-c329-ui.mjs` SHA-256 is `0156c76a07625b595c6a8499dc0b1fb6500f4d93768e29a073b1c97aa4c57059` before any C329 browser run. `node --check` passed; a separate `new Function` parse of the pass-through Source Pinch wrapper passed. The independent fixture and pinned bundle hashes matched the preregistration. The retained C327 Source receipt proves why C329 tests actual canvas size: canvas `[1024,808]` had been reported by the inherited clipped scene-pixel calculation as `[1024,768]`.

Each run uses one ordinary owned browser, actual UI controls/input and public Save. `--side=source|root`, `--negative=off|on`, and `--mode=press-only|press-move` are required; root also requires `--match-source=<same-polarity-and-mode source result.json>`. Start with Source press-only, OBrush press-only, Source press-move, OBrush press-move for Negative off, then repeat for Negative on. Pair every mode/polarity only with its own Source receipt. Keep all eight raw result files including failed setup or contact gates. C329 does not reuse C327 geometry as a replacement for fresh captures.

The official `web/dist` product build from integrated C327 base can be reused only if its source code is unchanged and its served WASM/JS hashes match the files. A build or reference file mismatch must fail before input. The harness records actual camera matrices and world-ray/radius calibration, direct completed Source Pinch calls, OBrush applied dab counters, normal DOM delivery, public geometry/GPU snapshots and full-stroke undo/redo. Any failed count remains in `protocol_failures` while the harness continues to release and save the public geometry where possible. A failed setup retains its partial result. Browser/Cargo and paired numerical scoring had not run at freeze time.
