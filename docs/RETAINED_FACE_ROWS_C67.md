# Retained original-face row lookup (C67)

The shipped ordinary Source primary picker already obtains ascending current-face candidates from the retained ordered tree. C66 still walked every original face to recover each candidate's canonical triangle row. C67 stores one bounded `u32` first-triangle row per original face when seeding the validated transient Source state. Retained, fully verified picks now visit only candidate original faces and perform the same f64 triangle intersections in the same face order. A quad still tests its first triangle before its second; equal-distance faces still prefer the earlier original face. Missing retained rows fail closed. The public unretained picker keeps its scalar full scan, and mirrored picking is unchanged.

The row array is shared across refreshed and balanced states, accounted in retained-state bytes, and included in the pre-allocation budget. Its indexing comes from the validated canonical face/triangle order and is used only while the borrowed state has been checked against the exact mesh. It is never serialized or authorized by a pointer or cached flag across a mutable mesh borrow.

The focused mixed quad/triangle fixture checks that a hit on the second triangle of the final quad resolves to triangle row 4 and original face 2. The existing 289-ray dense-sphere comparison checks indexed and full-scan face/triangle identity and exact hit coordinates; separate ordered-tree tests cover current deformed bounds and misses. The final shared-core workspace suite and strict native/WASM checks pass. The official web and macOS artifacts and a scoped owned-browser brush run are indexed in [the C67 evidence](evidence/sculptgl-retained-face-rows-c67-0.1.20.json).

This removes one O(original faces) walk from the verified primary pick, but each contact still validates the mesh and compares the retained state across the full mesh. The frozen 999,002-vertex, 60-second browser cohort was replayed on the C67 root build: all 24,000 pointer motions were scheduled, all public saves and Undo/Redo completed, 65 memory samples were retained, and the whole-model audit found finite useful deformation with no degenerate or reversed original faces. **Four responsiveness gates still fail.**

The runs delivered different coalesced contacts. The 1 ms CPU P95 difference is **not** a controlled regression or speedup estimate. Both remain far above the 16.667 ms CPU-frame gate, and C67's release queue did not clear by 100 ms. A separate native M2 release probe on the same fixture measured median 12.692 ms for `Mesh::validate` and 3.130 ms for `SourceGeometryNormalState::matches_mesh` across 12 calls each. Five useful prepared Brush dabs took 15.672–24.720 ms to prepare and 40.458–58.157 ms to apply after a 353.509 ms first application, changing 20,470 vertices overall. These are standalone native component timings with independent input, **not** attribution of the browser frame or a matched SculptGL comparison. They show why picker-only work is insufficient; deformation, normal/tree refresh and state/history ownership need profiling and GPU-resident integration. C67's 120-second and 10K/100K sustained cohorts remain unrun. The WebGPU point-program prototype remains isolated from shipped brush, document, history and fallback behavior. The 317-ID SculptGL inventory plus five hosted controls and ZBrush 2026.2.1 parity remain unverified.
