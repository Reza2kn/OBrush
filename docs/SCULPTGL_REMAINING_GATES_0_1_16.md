OBrush has added normal browser material Paint, original-face/corner-UV persistence, real OBJ UV return, and retained static quad subdivision. These are scoped foundations. Full SculptGL parity remains unverified, and the [ZBrush objective](FEATURE_PARITY.md) remains separate.

The [complete additive gate matrix](evidence/sculptgl-remaining-gates-0.1.16.json) retains all **317 stable baseline IDs**, their original source pointers and acceptance gates, plus the five later discovered hosted theme controls. It attaches each local observation to its own candidate version. The [initial inventory](SCULPTGL_PARITY.md) stays unchanged: its OBrush 0.1.14 absence/status fields are historical, rather than current claims. This is a work map, not a parity percentage.

## What the latest browser evidence establishes

[Retained actual OBJ return](SCULPTGL_OBJ_RETURN_CANDIDATE2.md) passes the unchanged original triangle and quad UV-return gates that failed in candidate 1. Both files are the original actual producer bytes, rather than replacements created to pass the importer. This does not establish complete OBJ object/group/MTL semantics or arbitrary supplied-normal retention.

[Material Paint and static subdivision](SCULPTGL_PAINT_STATIC_CANDIDATE2.md) pass four ordinary write-channel selections, all-off redo, older implicit retained material promotion/navigation, locked release/return-origin, and one original-quad/UV Add Level per static scheme. Complete saved projects, history and GPU geometry/material streams are checked. Two strict immediate Escape equality failures remain preserved: the queue is empty and geometry unchanged, while the first asynchronous read still shows the held material preview before the cancellation frame is drawn. A later [separate completion-aware cancellation check](SCULPTGL_CANCEL_COMPLETION_CANDIDATE2.md) passes exact restored project, prior Redo and quiet behavior after command/GPU acknowledgement. Matched cancellation timing remains open.

[Initial material/render/export checks](SCULPTGL_ATTRIBUTES_CANDIDATE1.md) retain useful Studio/PBR/Normal, flat/exposure, malformed recovery, checked attribute-loss policies and detach/Undo/Redo evidence. These image differences establish working controls and preserved state, not reference lighting, MatCap, environment, UV texture or complete render equivalence.

Earlier [0.1.15 camera/primitive corrections](SCULPTGL_HOST_CANDIDATE2.md) pass bounded rapid pan/orbit, the original raw wheel event and useful fresh primitive Draw. Original failures stay in their earlier receipts. Historical passes bind those candidate bytes and do not automatically refresh every later option or geometry change.

## Reference coverage and inactive workflows

The [reference browser characterization](SCULPTGL_REFERENCE_RUNTIME.md) is partial. Core tool/camera/primitive/file observations passed, but its mixed Add Cube read-only snapshot timed out. It cannot be treated as a completely passed reference suite. Actual deployed bundle/HTML/assets and real SGL/OBJ/PLY/STL exports have separate hashes; no source/deployment identity is inferred from matching labels.

The current reference exposes Sketchfab upload; authorization/login/upload and current endpoint behavior were not exercised. Sculpteo/Materialise print registration and the parameterized torus builder are commented-out source workflows. ASCII PLY/STL export helpers are separate from the exposed binary export controls. Current replay/autosave registration was not found in the pinned application. These records remain visible and are not counted as successful active workflows. Their absence does not remove ZBrush recovery or other desktop requirements.

Native packaging does not prove native GUI execution. Synthetic mouse traces do not prove physical tablet/touch or long-session performance. None of the locally passing feature labels or test counts close the remaining complete reference gates.
