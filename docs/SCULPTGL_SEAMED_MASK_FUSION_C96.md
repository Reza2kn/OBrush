# C96: selected Marching Cubes with a UV seam and nonuniform mask

The earlier mixed-UV fusion fixture used one UV coordinate per vertex and constant unmasked weight. This independently authored variant splits vertex 1 between UV coordinates 1 and 9 on four faces, and gives the eight left-box vertices unmasked `#MAT` bytes `[0, 64, 128, 192, 255, 32, 96, 160]`. The right box has no UVs and full unmasked weight. The left OBJ SHA-256 is `146d24ba020e9ddbff2fc0e5d401a52b2bafc0c355d4f89312737fe4583d061b`; the unchanged right OBJ SHA-256 is `9600c7b964ac0b35ebafda32d889f96bda59799ecc0e65092b5fa598ba924dbf`. The pinned SculptGL bundle SHA-256 remains `79b24bf6e1818cbb468c53cfe49783de419fd3e58f72b220aeb9308932e47600`.

Both applications selected the right then left boxes and ran Marching Cubes at resolution 16 with Relax topology off and on. OBrush required the visible UV-discard consent. Each output has 1,056 vertices and 2,108 triangles. After the unrelaxed one-to-one vertex mapping, all 2,108 oriented triangles agree. Maximum browser-save world-position difference is `1.450679320281757e-7` with Relax off and `3.2459885279663655e-7` with Relax on; Relax-on RMS is `1.159474463709226e-7`. Maximum RGB and roughness/metallic differences are `2.7055358842176247e-8` and `2.384185793236071e-8`. The maximum unmasked-weight difference is `9.163627623376414e-8` (RMS `1.8831320802976644e-8`). This small mask difference is retained rather than described as exact.

The isolated browser check exercised default rejection, explicit consent, closed output, exact save/GPU correspondence and undo/redo. A shared-core test imports the exact seam/mask OBJ and checks all three voxel modes for nine discarded UV coordinates, twelve discarded UV-indexed faces, retained nonuniform mask influence, and exact source restoration on undo. The [evidence index](evidence/sculptgl-seamed-mask-fusion-c96-0.1.20.json) records source, reference and browser hashes, comparison output, commands and limitations.

This tests one seam pattern and one mask pattern on overlapping boxes. The reference comparison covers Marching Cubes only; Smooth Surface Nets and Block have shared-core checks but no matched seamed/masked reference run yet. Selected affine parts, arbitrary topology, long-session responsiveness and production WebGPU integration remain open. It does not establish remeshing-family or ZBrush parity.
