# T02 normal-browser adaptive-topology preparation gate

Candidate parent: core commit `7037199eb892df827f28cf79cf5691d9e4a5200d`. Fixture and pinned SculptGL source hashes: [T01 preregistration](SCULPTGL_DYNAMIC_CONVERSION_T01_PREREG.md). T01 local core gate passed; this separate gate must use an official `scripts/build-web.sh` artifact and a normal browser click path, not direct Rust or private WASM calls.

Import the independent UV quad through OBrush File Open, add one source-static subdivision level, Save an `.obrush` project, and record the full project SHA-256 plus visible mesh channels. In the actual topology inspector, open **Adaptive topology**, verify the displayed lost-level, original-face and UV counts match the project; verify the Convert button is disabled until the acknowledgement checkbox is clicked. Click the checkbox and Convert button using their exposed `object.dynamic.acknowledge` / `object.dynamic.prepare` UI rectangles from `window.obrushBrushMetrics()` and ordinary pointer events. Do not synthesize an internal button callback.

Save after conversion and require: exactly one fewer retained level, no `multiresolution` or `surface` metadata, same visible position/triangle/RGB/mask/material words, `adaptive_detail_supported=true`, and no browser exception. Ordinary Undo + Save must match the pre-conversion project exactly; Redo + Save must match the converted project exactly. Reload the converted save via normal File Open and check channels and adaptive availability. Repeat conversion must be unavailable or a no-op. If visibility/scroll/selection/file-dialog setup fails, retain that failed receipt before changing coordinates or procedure.

The pinned SculptGL comparison remains a separate gate: load the same OBJ, activate its native Dynamic topology checkbox, measure face/UV/color/material/mask changes and behavior after deactivation. T02 is an OBrush consumer-route gate and cannot by itself promote `SGL-TOPO-DYNAMIC-ACTIVATE`. Neither T02 nor T01 covers factor sliders, local collapse, alternate meshes, native GUI or sustained editing performance.
