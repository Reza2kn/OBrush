# C105: versioned normal-frame detail transport in the studio

New source-static hierarchies now serialize `sculptgl_static_smooth_v3` or `sculptgl_static_linear_edges_v3`. On Lower they retain C101's even-row analysis. When a changed coarse level is reconciled upward, the shared Rust core uses [C104's](SCULPTGL_RING_CORE_C104.md) UV-aware source ring map and face-averaged normal frame to transport the fine residual. The derived ring map is built once per parent/child topology and shared across history snapshots; a loaded `v3` project reconstructs it after validating every level. Previously saved `v1` and `v2` hierarchies retain their earlier world-offset policy.

On the same independently authored all-seamed tetra, quad cube and mixed pyramid OBJ files used in [C102](SCULPTGL_UV_COARSE_EDIT_C102.md), the normal `Document` Add Level → Lower → direct coarse edit → Higher path now gives maximum mapped final-position component differences of `1.4901161e-8`, `5.9604645e-8` and `2.9802323e-8` from the pinned SculptGL captures. The edit is `(0.125, -0.09375, 0.0625)` on the same physical coarse vertex. Before this change the mixed pyramid's final displacement differed by `0.037433`. A dedicated regression loads a serialized `v2` hierarchy and verifies its old world-offset calculation exactly. These are controlled geometry comparisons; the direct vertex edit deliberately isolates the hierarchy from each application's brush behavior.

The rebuilt browser passed five normal import/Add/Lower/Higher/save/GPU/history cases across the three same-byte reference OBJ files and a 1,536-quad UV grid in smooth and linear modes. A further normal browser Draw stroke on the grid's coarse level changed 18 of 1,538 coarse vertices; Higher changed 174 of 6,146 fine vertices. The visible GPU buffers matched each saved mesh, the brush's undo and redo restored exact projects, reload matched, Delete Lower kept a valid singleton `v3` hierarchy with exact undo/redo, and no work remained after release in the scoped checks. The observed stroke's maximum coarse/fine displacement was `0.015955622` / `0.013758449` world units. This confirms the product route executes `v3`; it is not a reference brush-response or long-session speed comparison. Browser artifacts and numerical receipts are indexed in [C105 evidence](evidence/sculptgl-static-frame-c105-0.1.20.json).

A local two-level edit/reload/navigation test returns the edited fine positions exactly after Lower/Higher. Its first assertion required the **entire serialized project** to be byte-identical after that navigation and failed: Lower legitimately rewrites the retained coarse analysis while leaving the visible fine positions unchanged. The final test checks exact fine positions and surface topology and retains the failed assertion in the test log/evidence record. No second-level edited SculptGL reference comparison has been run.

The later [C106 comparison](SCULPTGL_TWO_LEVEL_FRAME_C106.md) supplies that second-level edited reference check and corrects the chained face-order gap it exposed.

Deleting levels trims the retained topology maps alongside their parent/child meshes. A two-direction regression keeps either the lower or higher half of a three-level `v3` hierarchy, reloads it, edits the remaining coarse level, returns to the fine level and roundtrips the project. This closes a cache-lifetime bug found in review before final packaging; arbitrary edited deletion sequences remain unpaired with the reference.

Broader SculptGL multiresolution behavior remains open: more topology/UV classes, multiple paired edited levels, thin/folded surfaces, brush response, texture pixels, native GUI feel and sustained latency. WebGPU is still a separate prototype. In particular, the retained map avoids rebuilding ring order per edit, but normal-frame synthesis still scans fine geometry; the million-vertex responsiveness gates have not been rerun or passed here. This change does not establish SculptGL or ZBrush subdivision parity.
