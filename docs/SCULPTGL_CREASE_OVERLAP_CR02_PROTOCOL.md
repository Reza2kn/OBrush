# CR02: default-pressure Crease, closer front-surface comparison

CR02 is a new gate following retained CR01. It does not revise the failed CR01 protocol or receipts. Use the same independently authored sphere (SHA-256 `572bed8539b5fb2606f9362e12e94964aa24b2b232f404197b8ab930346aaa08`), pinned SculptGL commit/bundle, eight 13-point alternating held strokes at local X `0.25` and Y `-0.18..+0.18`, normal SGL import, Solo, Crease selection, X symmetry, and matched mouse pressure `0.5`. Freeze OBrush's actually published defaults: local radius `0.180`, strength `0.35`, `pressure_strength=true`, `pressure_radius=false`, adaptive detail off, alpha None, continuous off. Do not force pressure off. Capture and report the actual effective brush strength in both apps; if not directly observable from published state/call traces, mark it unknown and do not claim geometry parity. Reference settings remain visible radius equal to nearest integer projection of local `0.180`, intensity `0.35`, negative true, culling/lock off, alpha None.

The CR01 eight-stroke geometry/Save/Undo/safety bounds remain as independent CR02 checks. Add a direct admission trace with side labels or screen-to-local hit-center signs for each app; require at least one primary and one mirror Crease dab per stroke. Add a normal-browser closer camera view **after** the eighth stroke using only visible wheel/camera controls. Set the projected `0.36`-world-unit held path span between 300 and 360 CSS px, keep both cameras within 1% span and both 13-point paths on the front visible sphere. Park the cursor, capture 1600×1000 screenshots with the same material/background mode where possible, and crop a radius-220 CSS-pixel square centered on the middle path point. Capture before-stroke baseline at this same closer camera scale in separate clean replay sessions; no digital image zoom substitutes for closer camera rendering. Require no WebGL errors and no background-colored interior gaps in a radius-180 disk. Report changed pixels, max-channel/RMS RGB, mesh edge-stretch/face flips/tiny faces, and worst-face close-up IDs. Human visual review must still be reported separately. If the closer view cannot be established through visible controls or changes stroke geometry, retain failure and do not tune the window.

Record official build/reference/harness/fixture SHA-256 values, exact controls, projections, admitted calls, per-stroke Save hashes, snapshots and failures. These thresholds are a bounded visual and geometry safety witness only; complete SculptGL and ZBrush parity rows remain open. Chrome is reserved for Q05/MRP10 before CR02.
