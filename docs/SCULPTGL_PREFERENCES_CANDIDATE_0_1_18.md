# Preferences and alpha consumer checks — initial 0.1.18 candidate

The frozen 0.1.18 candidate1 passes the named browser checks for all fourteen tools’ in-session preferences and temporary Smooth/Mask behavior. Candidate2 additionally passes the original alpha conversion/library/rejection cases after the selector layout fix. The compound release stability gate remains failed. This is local consumer evidence, not SculptGL or ZBrush parity. Read [the feature contract](FEATURE_PARITY.md) and the frozen [SculptGL inventory](SCULPTGL_PARITY.md) for the broader gates.

All three original runs used the unchanged `check-sculptgl-preferences.mjs` helper SHA256 `12caee2aca7dfcf806ca6842ef5477ba5eced9a2e94eb46f33aba6bae8a12d7b`, an owned isolated Chrome/CDP profile and ephemeral localhost server, normal rendered controls, trusted pointer/keyboard input, actual PNG file inputs and real project downloads. No application/tool/mesh assignment, user tab or native accessibility interaction was used. [The evidence](evidence/sculptgl-preferences-initial-0.1.18.json) preserves all three failed run statuses, exact candidate/helper hashes, every completed case gate and separate diagnostics.

The successful cases on 0.1.18 candidate1 cover:

- All fourteen tools retain their actual radius, strength, invert, screen-radius and supported lock fields through normal tiles and keyboard selection. Paint’s normal blue swatch and scalar targets remain exact; other tools retain their existing color/material targets. Settings preserve the whole saved document and prior geometry Redo.
- Shift Smooth, Ctrl Mask and Ctrl+Shift Mask priority use their own saved options in both hover and press. Matched direct-tool and temporary-tool gestures produce exact saved project/GPU outputs, whole-stroke Undo/Redo and unchanged 0/200/800 ms post-completion probes.
- All 42 actual project/GPU pairs across the two original runs were independently reconstructed with Python `struct.pack`: original 40-byte position/normal/display-mask/RGB, optional 8-byte materials, UV stream and indices. Every pair is exact. This confirms those saved/visible domains, not independent brush-response parity.
