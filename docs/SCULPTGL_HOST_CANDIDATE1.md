## Individually completed scope

An independently authored noisy closed sphere has 2,522 vertices, 5,040 triangles, nonuniform RGB and 48 fully protected points. All **14 brushes**—Draw, Clay, Inflate, Smooth, Flatten, Crease, Move, Mask, Paint, Morph, Pinch, Twist, Local Scale and Drag—made useful edits in their intended channel at the default 0.180 world radius / 35% strength. Morph used ordinary Store and Draw preparation. Original fully masked positions stayed exact, complete public project Undo/Redo matched byte-for-byte, and visible vertex/index buffers matched the saved document. Drag used an 81-point fast trace. The release probes found no subsequent geometry change or pending dabs in these named samples.

The probes occur after release dispatch and asynchronous GPU readback, with additional waits of 0, 200 and 800ms. They **do not measure finalization latency, input-to-photon response or long-session performance**. A useful short trace does not establish response-curve or surface-quality parity.

Normal controls committed screen sizing, hardness, culling, symmetry offset, Clay/accumulation, tangent Smooth and Move topology/normal settings without changing the saved project. Separate paired Clay, accumulation, tangent Smooth and normal Move gestures produced useful different outputs. Ordinary outside-camera zoom samples at fixed 75px radius produced useful edits at two zoom states. Camera projection/FOV, all three mode selections, pivot and Front/Left/Top controls changed their intended state while preserving the project. Each axis's normalized eye-target vector matches its independent expected direction within `2e-6`; all three normal rotation traces changed the actual view matrix.

Actual Add Sphere/Cube/Cylinder/Torus commands selected their output and left existing parts exact. Selected merge and its bake option passed counts, project history and visible GPU checks. ASCII/binary PLY and ASCII/colored binary STL imported through both Open and Append with expected geometry, supplied PLY normals/RGB and VisCAM RGB, exact undo/redo and real visible buffers.

All five normal export choices—OBJ, text STL, colored binary STL, text PLY and binary PLY—produced real downloads. Independent parsing matched their declared position/index/normal/color channels; STL normals meet the unchanged `1e-6` bound. PLY preserves its exported f32 normal/RGB channels; STL's facet color is the declared averaged 5-bit approximation. The export actions preserved the complete project. One truncated PLY was rejected while preserving the document and existing redo.

Five normal locked Draw stamp cases used an independently generated asymmetric 16×16 PNG. Held previews changed geometry, held the press center fixed and used equal travel radii with the expected 90° alpha orientation. Returning to the same absolute endpoint restored the same full GPU data. Release committed one exact history step, protected positions stayed exact and the bounded release probes were quiet. Exact return to press, Escape, viewport resize and a navigation chord restored the original project and preserved the existing redo. No Save command was used during a held preview.

These are **36 individually successful named local cases among 37 distinct observed cases**, including startup; the counts are not a feature/parity denominator. Supported stamp brushes beyond this Draw sample, arbitrary option combinations, tablet/touch/native interaction, full footprint/DPR/resize behavior, transformed interchange, topology, materials/UV/SGL host support and reference-matched quality/performance remain separate obligations.
