# C267 preregistration: single-pass Legacy-normal rollback allocation

This trial starts from OBrush commit `d13eb29ac68747e494ad312cd010e41990ddb5b0` and the unchanged C264 million-vertex Source Brush baseline in [SCULPTGL_MILLION_CURRENT_C264.md](SCULPTGL_MILLION_CURRENT_C264.md). It is a shared-core memory/copy experiment, not a SculptGL parity result.

The unvalidated candidate is retained in ignored `.artifacts/c267-single-pass-rollback.patch`. The source tree was restored before the independent C268 face-box-page trial. C264's measured old-copy mean of only `0.400 ms` bounds this candidate's possible direct gain; no browser run or parity claim is justified for C267 alone.

`SourceGeometryStroke::apply_validated_controlled` currently copies every Legacy normal before each controlled dab so it can restore those words if a later pass fails. With exactly one prepared pass, `apply_access_math` performs all fallible work before `recompute_normals_near_vertices_cached`; the remaining publish path cannot return `Err`. The candidate omits this full-array copy only when there is at most one prepared contact. Two-pass mirrored operations keep their existing backup and rollback. The candidate changes no selection, brush math, normal refresh, history, file IO, renderer, or public controls.

Before admission, check exact f32 words and reports for independent one-pass success and failure fixtures against the saved original algorithm, and test a two-pass failure after primary mutation restores positions, normals and history exactly. Preserve existing storage-limit and stale-domain behavior. Run `cargo fmt --all -- --check`, focused and full workspace tests, strict native/WASM Clippy and `scripts/build-web.sh` when the shared build lane is released. If accepted for browser measurement, run the frozen C264 fixture/protocol and independent before/after/stable/Undo/Redo audit; record delivered dab count, old-copy/geometry stage means, RAF P95, release acknowledgment, and all four gates. A smaller copy is only a direct allocation reduction until that measurement; any different delivered-dab counts make end-to-end comparisons observational. Reject if exact behavior or full gates fail and retain failed receipts.
