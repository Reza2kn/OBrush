# C162: Ctrl background mask gesture

The pinned SculptGL `SculptGL.js` uses a Ctrl gesture that starts without a sculpt hit to enter `MASK_EDIT`: release at the last mouse-move coordinates equal to the press coordinates calls Masking `invert()`, while a changed last position calls `clear()`. OBrush now routes the same empty-viewport gesture to the existing shared-core mask transactions. A gesture is admitted only for a visible active part, while Brush mask selection mode is active, with no scene hit or navigation press. It is cancelled if focus, viewport, active part, or document revision changes, or when a command finishes the current stroke. Region masks, Ctrl strokes on geometry, other viewport controls, and native/browser geometry behavior retain their existing routes. The core owns the mask values and Undo/Redo; the host only classifies the pointer gesture.

An owned Chrome/CDP replay used trusted Ctrl mouse events on the normal canvas in each application.
