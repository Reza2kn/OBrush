# Per-object Source symmetry-offset foundation

Pinned reference: SculptGL `8e45dafc0f7906e5238dfffc1a2df742bd25f29d`, `src/gui/GuiScene.js` (active-mesh `SymOffset` slider, -1..1 at 0.001 step), `src/mesh/Mesh.js` (`getSymmetryOrigin`), `src/math3d/Picking.js` (reflected local near/far ray), and `src/render/shaders/ShaderBase.js` (line plane). In SculptGL, `computeLocalRadius` uses the octree root's **loose** local AABB half-diagonal. It is not the tight vertex AABB and the offset is not in world units.

OBRush base: `e4890c9e9b94d9d6b5a03ece84fa1d49f577275f`. Independent two-object SGL fixture: `crates/obrush-core/tests/fixtures/independent-affine-two-mesh.sgl`, SHA-256 `99e107226fd5bdfeb687a4d92a61eebcec1abb2e910184e35aa58808ace105fd`.

The implementation stores a finite [-1,1] f64 offset on each Source object in versioned `.obrush` scene metadata. Absent fields in earlier projects read as zero and zero is omitted on save. Changing the active object's offset records one complete document undo event; selecting another object restores its own offset. The ordinary Source brush UI reads the active object's value and passes it to the existing Source mirror plane, which uses the retained Source tree's loose bounds. Plain OBrush meshes without Source metadata continue to use the transient per-tool Source preference. Legacy `BrushSettings.symmetry_offset` remains an absolute local X offset and is not reinterpreted.

The SculptGL `.sgl` binary has no symmetry-offset word. Export preflight counts each nonzero offset as an omitted object and `RejectLoss` must reject it; `AllowAndReport` may export with that loss declared. This foundation does not make the viewport line follow the nonzero Source plane: the existing reference-center line remains an explicitly offset-zero preview. Source brush shape, camera/picking, and line parity remain open.

Tests use normalized offsets 0.25 and 0.375, a distinct transient preference -0.75, active-object switching, `.obrush` round-trip, undo/redo, rejection of nonfinite input, and SGL omission preflight. The independent triangle probe uses vertices (0,0,0), (2,0,0), (0,4,0) and offset 0.5 to verify the Source mirror plane's radius scaling. It checks OBrush invariants; no exact browser/reference numerical comparison is claimed here.

The authored fixture now explicitly uses Source's unprotected convention. Its three targeted tests then passed, and the complete workspace test rerun passed.
