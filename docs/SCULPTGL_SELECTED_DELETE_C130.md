# C130: selected-group deletion on a three-part scene

The normal OBrush scene-panel Delete button previously called `delete_subtool(active_id)`, so a multi-selection removed only its active part. The shared Rust `Document` now has `delete_selected_subtools`: it validates the entire candidate scene, removes the selected set in **one undoable transaction**, keeps an unselected survivor active, and delegates an all-selected deletion to the existing checked empty-scene transition. The browser Delete button calls that method. Geometry, file IO and history remain in `obrush-core`; the native and WASM hosts use the same document operation.

An independently authored SGL v3 fixture has three separated, closed six-face boxes at X `[-2,-1]`, `[0,1]` and `[2,3]`, each with Y `[0,1]` and Z `[0,1]`. Its 1,560 bytes have SHA-256 `939110d73dec934f0af70fb5c364eeb18f3ce18608449fe76804896c50c9c0ae`; the writer and exact values are retained in `.artifacts/scene-multiselect-c130/`. The pinned SculptGL revision `8e45dafc0f7906e5238dfffc1a2df742bd25f29d` imports the right box selected. Physical Shift-clicks on left, center, then left again produce selected indices `[2] → [2,0] → [2,0,1] → [2,1]` without altering any vertex array. Its `GuiScene.deleteSelection` handler removes the right and center boxes. Undo returns three boxes, and redo returns one.

The normal OBrush browser imports the same fixture and uses scene-panel Ctrl-clicks on part IDs 1, 2, then 1. Selected IDs follow `[3] → [3,1] → [3,1,2] → [3,2]`. Clicking its visible Delete button leaves only part 1. Ordinary Command+Z restores the exact pre-delete 7,778-byte project SHA-256 `1159d48c65b426d5f407bf4085567d1b00dc8c65da38442e958e4b3e3206f0bd`; Command+Shift+Z restores the exact post-delete 2,912-byte project SHA-256 `e1a1ef62b5c4833d67462367f1fb0ad6eb5fcfb3a3996c4dc56d4c1167fac2bf`. The project after Undo was captured through the normal Save project button, because the separate WebGPU resident diagnostic correctly refuses to open a capture on a redo branch. Both successful browser runs report zero console errors, exceptions, blocked external requests and cleanup errors. The final app WASM is SHA-256 `5a3ad62d74e1788562f852fa053212596548634fc66cc72be7a67705823290fe`.

The shared-core test also uses a rich three-part document, deletes two selected parts atomically, verifies the survivor, exact whole-project Undo/Redo, then deletes the final selected part into an empty scene and undoes that transition. The source's remaining box has **no selection** after deletion; OBrush selects that survivor because its nonempty-scene invariant currently requires one active selected part. SculptGL's Undo restores selection membership in a different order than before Delete, while OBrush restores its exact pre-delete order. Multi-part duplicate, isolate, transform and export scope; full selection policy parity; large scenes; native GUI; and complete SculptGL parity remain open.

Final `cargo fmt --all --check`, 100 workspace/all-target test-result summaries (**2,456 passed, zero failed, one ignored**), strict native and WASM Clippy, and `scripts/build-web.sh` passed. `scripts/package-macos.sh` produced an ad-hoc-signed app that `codesign --verify` accepts; its executable SHA-256 is `c77380cd048d99eea3b9d7ba22de7a91967723dca4439ad42ab26894af6c11ef`.
