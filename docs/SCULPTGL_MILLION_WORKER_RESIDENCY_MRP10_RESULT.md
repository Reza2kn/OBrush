# MRP10: persistent Source Worker lifecycle — scoped pass, no performance admission

The query-gated Source Worker trial can now reuse one initialized Worker across consecutive **successfully committed** Source Draw gestures. The ordinary browser path is unchanged. Each gesture still starts a fresh Worker-side transaction from the current public project and checked retained packet, and the main shared-core final publication still verifies the complete scene, candidate, retained state and history. Cancellation, rejection, disable and idle unexpected replies destroy the reusable Worker. Distinct message IDs and reset per-gesture Source sequence are checked. This is an architectural lifecycle step, not a solution to the million-vertex latency gap.
