# C101: versioned static-level lowering

The [C100 paired UV comparison](SCULPTGL_UV_SUBDIVISION_C100.md) found one concrete navigation mismatch: after adding a static level, SculptGL's first Lower copies the fine mesh's even vertices into the coarse level, whereas OBrush retained the pre-subdivision coarse positions. C101 adds a versioned `sculptgl_static_smooth_v2` / `sculptgl_static_linear_edges_v2` hierarchy for newly created studio levels. The Rust core copies validated fine even position, RGB, mask and material rows into each next lower level, leaving that level's original faces and corner UVs bound. Older `v1` saved hierarchies retain their previous exact-coarse policy.

The same three independently authored all-seamed OBJ fixtures were imported through actual pinned SculptGL and rebuilt OBrush browser controls. One smooth level was added, then Lower and Higher were used. Faces are paired by physical corners because the importers order indices differently.

| Fixture | Lower: maximum mapped position error | Lower: maximum mapped UV error | Higher: maximum mapped position error |
| --- | ---: | ---: | ---: |
| Tetra, 4 triangles | 0 | 2.5273e-8 | 1.4901e-8 |
| Quad cube, 6 quads | 1.7954e-8 | 0 | 1.7954e-8 |
| Mixed pyramid, 1 quad + 4 triangles | 2.7633e-9 | 2.6703e-8 | 8.5787e-9 |

All 4/6/5 lowered faces and 16/24/20 returned child faces map; the respective UV coordinate counts remain 12/24/16 and 24/54/33. The browser's fine active mesh returns exactly at the `f32` word level, while its complete project changes because the stored coarse level now records the analysis. The original reference also changes a few fine `f32` words on Higher, so the tiny returned-to-reference differences above are retained. No acceptance tolerance was preregistered; these numbers describe the observed fixtures.

An expanded four-stage channel comparison exposed a separate input mismatch: for OBJ vertices without explicit color, OBrush's bounded `import_obj` path used clay RGB `[0.65, 0.69, 0.74]`, while the pinned SculptGL importer produced white `[1, 1, 1]`. The final shared-core import now uses white only for that missing OBJ channel. On both colorless fixtures, mapped RGB is exact at input, fine, Lower and Higher; the explicitly colored cube differs by at most `8.5511e-8` in RGB. Across all three fixtures and four stages, roughness and metalness differ by at most `4.8723e-8` and unmasked weight is exact. Native Rust and browser WASM positions, UVs, RGB, materials, masks and face indices match as `f32` words at input and fine level. Existing saved colors and the older `Mesh::from_obj` policy are unchanged. These results do not verify texture pixels or painted/color-edited level navigation.

The final rebuilt browser passed real save/GPU correspondence and exact Add Level undo/redo across all three same-OBJ cases: 22 downloads and GPU checks including a retained static-v1 project reopened to verify its older navigation contract. A second 1,536-quad UV grid passed both new smooth and linear modes on the final build, including normal project save/reload, level navigation and 15 GPU/save checks. The complete workspace passed 2,395 tests across 70 groups, formatting, strict native and WASM Clippy, WASM check, the official browser build and the signed local macOS package. A failed initial browser assertion was preserved: it compared complete fine-project bytes before and after Lower, although the newly updated coarse level legitimately changes that document. The corrected gate compares the active fine mesh and independently checks that the hierarchy changed.

This closes the initial **unedited** down/up geometric mismatch on three small fixtures, not the full SculptGL multiresolution workflow. SculptGL's Higher synthesis applies stored detail in a normal frame; OBrush still transports coarse edits as world-space deltas. Multi-level and coarse-edit behavior have local Rust checks but no paired reference comparison. Shared-edge UV charts, texture pixels, native GUI, physical stylus, larger reference fixtures and sustained responsiveness remain open. Full SculptGL and ZBrush parity are unverified. [C101 evidence](evidence/sculptgl-uv-navigation-c101-0.1.20.json) binds the actual browser sessions, comparisons, hashes and final checks.
