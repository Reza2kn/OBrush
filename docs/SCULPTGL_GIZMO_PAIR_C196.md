# Paired pinned rotation on the same sphere (C196)

This pairs [the C195 physical SculptGL reference](SCULPTGL_GIZMO_PHYSICAL_C195.md) with the normal OBrush browser, using the same independently authored 266-vertex / 528-triangle OBJ (SHA-256 `4bfebeb8ac713741ee5b70dedcefd8d746e21f610ebc788783f1008cc9d375ed`). The pinned source result is `.artifacts/sculptgl-reference-runtime/gizmo-c195-oracle-c6d835c0-45a9-4d20-a8b1-6def918d1857/result.json`, SHA-256 `3733efa366e26889b8cddb61ba087186da32d3cd9cddadba404dcb7cf949ab39`.

Run `node scripts/check-transforms.mjs web/dist gizmo-pair-c195-f32 --paired-gizmo-reference .artifacts/sculptgl-reference-runtime/gizmo-c195-oracle-c6d835c0-45a9-4d20-a8b1-6def918d1857/result.json` against the rebuilt browser bundle. The six-case result is `.artifacts/transform-browser/gizmo-pair-c195-f32-63326706-97d4-4b86-9360-2501279b0808/result.json`, SHA-256 `6f819e121572f9b2b64a67b2d7ee182a436a64e7053554123d15ffe39ad648cd`; harness SHA-256 `1ed5139c3a0bbad1a23a4c0eb10698adebfb34aed473b82d7f9f3ed406113291`, served WASM SHA-256 `8938b3bc7213880a36dbd656cb6b41c4ba9555b8eaf61bad842eb6b8271e76d6`.

For each X/Y/Z axis, OBrush imported the same public OBJ, enabled mask-respecting transforms through the normal UI, and received a real browser pointer press, 30-pixel tangent drag and release on its arc. Each measured preview angle matched the pinned `-7 × tangent distance / minimum viewport side` rule within 0.003 degrees; its mask-weighted saved positions matched an independent rotation oracle within `7.11e-8`. All seven fully protected vertices remained exact, all source unmasked weights mapped exactly to OBrush masks, and GUI Undo/Redo recovered exact saved projects.

The corresponding same-angle numeric runs use the reference's *measured physical-drag angle* as OBrush's visible input, then compare every mapped final vertex with SculptGL's physical gesture output. Maximum position differences were `7.685e-8` (X), `8.380e-8` (Y), and `6.975e-8` (Z). This compares geometry at identical angles while allowing the two UIs' distinct gizmo screen locations. The result reports no JavaScript or GL errors, actual 4× MSAA, and six passing case gates.

The first paired attempt is retained at `.artifacts/transform-browser/gizmo-pair-c195-b95f2f9a-b14d-4320-93a9-df1ab4b8f215/result.json`, SHA-256 `c35cee8f97478ae4e56a6b5ceda02c158d97827856c947fa4271eb76e6fc084f`. It failed before comparisons because OBrush's public JSON prints shorter decimal strings than the source's full f32 decimals; matching coordinates by their f32 words resolved the input mapping without changing output tolerances.

This is one masked sphere at the default pose with synthetic browser mouse events. Other meshes and poses, physical tablet input, long-session latency, complete Transform controls, and ZBrush remain open. The normal OBrush editor still uses WASM geometry and WebGL2; this is a behavior comparison, not WebGPU integration.
